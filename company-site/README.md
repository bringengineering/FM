# Bring Care company website

브링엔지니어링의 시설관리(FM) 회사 소개 홈페이지입니다.

## 주요 내용

- 시설 운영, 임대·입금, 민원, 공사·견적, 안전 점검, 운영 보고 소개
- 브링엔지니어링 사업자 정보와 사업장 위치
- 모바일·태블릿·데스크톱 반응형 구성
- Firebase Hosting용 정적 결과물과 Sites용 서버 빌드 지원

## 실행

```bash
pnpm install
pnpm dev
```

## 빌드

```bash
pnpm build
pnpm export:firebase
```
