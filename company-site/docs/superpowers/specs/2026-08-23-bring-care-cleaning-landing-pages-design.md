# BRING CARE 네이버 광고용 청소 랜딩페이지 설계

작성일: 2026-08-23

## 1. 목적

기존 BRING CARE 회사 사이트의 전문적이고 신뢰도 높은 시설관리 이미지를 유지하면서, 네이버 파워링크 방문자가 검색한 서비스의 가격·작업 범위·현장 증거·상담 방법을 첫 화면에서 바로 확인하게 한다.

최종 전환 흐름은 다음과 같다.

`네이버 검색 → 서비스별 랜딩페이지 → 전화 또는 간편 견적 → 건물주 식별 → 청소 계약 → 건물관리 상담`

최우선 성과지표는 클릭 수가 아니라 신규 관리건물 수다. 보조지표는 건물주 문의 수, 건물주 리드 비용, 관리상담 전환율, 건물관리 계약 비용, 청소 공헌이익이다.

## 2. 참고 방향

### 기존 BRING CARE 사이트에서 유지할 요소

- 파랑·남색 중심의 전문적인 브랜드 색상
- 넉넉한 여백과 선명한 큰 제목
- 현장, 연결, 기록을 강조하는 시설관리 관점
- 실제 사업자 및 회사 정보에 기반한 신뢰

### 도움드림에서 참고할 요소

- 서비스 종류가 빠르게 이해되는 메뉴와 카드
- 전문성, 친환경, 보험, 견적 등 신뢰요소의 짧은 제시
- 실제 시공내역을 통한 증거 제공
- 전화번호와 간편 견적을 반복 노출하는 전환 구조

### 경쟁 광고에서 피할 요소

`꼼꼼한 청소`, `전문인력`, `최신장비`, `친절상담`, `합리적인 가격`, `완벽한 청소`처럼 대부분의 업체가 반복하는 표현을 핵심 차별점으로 사용하지 않는다. 필요할 때 보조 신뢰문구로만 쓴다.

BRING CARE의 핵심 차별 문장은 다음과 같다.

> 청소하면서 건물까지 봅니다.

## 3. 디자인 방향

승인된 방향은 **브랜드 × 빠른 전환 혼합형**이다.

- 기존 회사 홈페이지와 동일한 브랜드 체계를 사용한다.
- 도움드림처럼 서비스, 가격, 전화, 견적을 빠르게 찾을 수 있게 한다.
- 일반 청소업체와 달리 작업사진뿐 아니라 이상사항 발견과 건물주 보고를 시각화한다.
- 과장된 1위, 최우수, 100% 만족 같은 검증되지 않은 표현은 사용하지 않는다.

## 4. 페이지와 핵심 메시지

### `/stair-cleaning`

- 검색 의도: 원주계단청소, 원주공용부청소, 원주원룸정기청소
- 제목: `깨끗하게만 하지 않습니다. 건물 상태까지 확인합니다.`
- 가격: `월 4회 6만원부터`
- 설명: `계단·복도 정기청소부터 조명·누수 흔적·적치물 확인까지. 작업 후 사진으로 확인하세요.`
- 주요 작업 범위: 계단, 난간, 복도, 현관, 우편함 주변, 공용창과 문

### `/building-care`

- 검색 의도: 원주건물관리, 원주원룸관리, 원주다가구관리
- 제목: `멀리 있어도, 우리 건물의 오늘을 확인할 수 있습니다.`
- 가격: `지역 공동관리 월 8.9만원`
- 설명: `공실, 세입자 문의, 입퇴실, 건물 상태와 처리 결과를 연결해 건물주에게 보고합니다.`
- 주요 관리 범위: 공실 확인, 공용부 점검, 민원 연결, 입퇴실 지원, 소규모 보수 연결, 사진 보고

### `/move-in-cleaning`

- 검색 의도: 원주입주청소, 원주이사청소, 원주원룸입주청소
- 제목: `새 공간의 첫날, 작업 전후 사진으로 확인하세요.`
- 가격: `원룸 10만원부터`
- 설명: `현관, 주방, 욕실, 창틀과 바닥의 작업 범위를 먼저 안내하고 완료 후 사진으로 확인합니다.`
- 주요 작업 범위: 현관, 주방, 욕실, 창틀, 수납장, 바닥

모든 가격은 현장 크기, 오염도, 작업 범위에 따라 달라질 수 있다는 조건을 가격 가까이에 표시한다.

## 6. 사진과 현장 증거

사진은 BRING CARE 네이버 블로그 `https://blog.naver.com/bringcare`의 실제 게시물에서 선별한다.

우선 활용할 범주는 `브링케어 현장기록`이며 현재 12개 글이 확인된다. 주소판 교체, 호수판과 벨 커버 정비, 출입구 안내판 정비 등은 건물관리 페이지에서 “청소하면서 건물까지 본다”는 차별점을 증명하는 자료로 사용한다.

사진 사용 원칙:

- 네이버 이미지 주소를 직접 연결하지 않고 사이트 자산으로 보관한다.
- 각 현장 카드에 블로그 원문 링크를 제공한다.
- 주소, 호수, 얼굴, 차량번호, 연락처 등 식별정보가 보이는 사진은 제외하거나 가린다.
- 실제 작업과 관계없는 스톡사진은 핵심 증거 구역에 사용하지 않는다.
- 같은 사진을 서로 다른 작업처럼 중복 사용하지 않는다.
- 사진 설명은 확인 가능한 사실만 적고 작업시간, 원인, 비용을 추측하지 않는다.

입주청소와 계단청소의 실제 현장사진이 블로그에 충분하지 않으면, 빈 공간을 타사 사진이나 생성 이미지로 채우지 않는다. 우선 작업 범위와 운영 방식을 그래픽 카드로 설명하고 실제 사진이 확보된 뒤 교체한다.

## 7. 구현 구조

세 페이지를 복제하지 않고 공통 랜딩 컴포넌트와 서비스별 설정 데이터로 구성한다.

- 공통 요소: 헤더, 첫 화면, 신뢰 띠, 범위 카드, 현장기록, 가격, 진행 과정, FAQ, 견적 양식, 하단 고정 버튼
- 서비스별 데이터: 경로, 검색 제목, 설명, 제목, 가격, 포함 범위, 사진, FAQ
- 각 경로는 개별 검색 제목, 설명, Open Graph 정보를 가진다.
- 기존 `/`, `/consult`, `/field` 경로와 기능은 유지한다.

## 8. 상담 흐름과 데이터

### 전화 상담

- 전화번호: `010-6566-3606`
- 모바일에서 누르면 즉시 전화 앱으로 연결한다.
- 화면 상단, 첫 화면, 마지막 CTA, 모바일 하단 고정 영역에 제공한다.

### 간편 견적

필수 입력은 최소화한다.

- 이름
- 연락처
- 건물 위치 또는 지역
- 건물 정보: 층수, 세대수, 평형 중 서비스에 필요한 항목
- 개인정보 전달 동의

상담 메일에는 다음 정보도 자동으로 포함한다.

- 관심 서비스
- 랜딩페이지 경로
- 유입 검색어 또는 광고 매개변수
- 접수 시각

기존 상담 메일 전송 방식을 재사용한다. 성공 시 기존 완료 페이지로 이동한다. 전송 실패 시 오류 내용을 알리고 전화 상담과 신청 내용 복사를 제공한다. 중복 전송 방지를 위해 전송 중 버튼을 비활성화한다.

## 9. 반응형·접근성 원칙

- 모바일 첫 화면에서 제목, 가격, 실제 사진, 전화와 견적 버튼이 과도한 스크롤 없이 보이게 한다.
- 모바일 하단 고정 버튼이 본문과 입력창을 가리지 않게 여백을 둔다.
- 모든 사진에 구체적인 대체 텍스트를 제공한다.
- 버튼, 링크, 입력 항목은 키보드로 사용할 수 있어야 한다.
- 색상만으로 상태나 의미를 전달하지 않는다.
- 작은 회색 글자나 과도한 애니메이션을 피한다.

## 10. 검증 기준

- 세 경로가 모두 정상 응답하고 서비스별 제목과 가격을 표시한다.
- 전화 링크가 `tel:01065663606`으로 연결된다.
- 견적 양식이 관심 서비스와 유입 정보를 포함해 전송한다.
- 전송 성공, 전송 실패, 필수값 누락 상태가 명확하다.
- 블로그 원문 링크와 사진 설명이 올바른 현장을 가리킨다.
- 기존 홈페이지, 상담, 현장 앱의 동작이 깨지지 않는다.
- 데스크톱과 모바일에서 가로 넘침, 겹침, 잘린 버튼이 없다.
- 사이트 빌드와 관련 자동 검증이 통과한다.

## 11. 이번 범위에서 제외할 항목

- 네이버 광고 캠페인 활성화와 입찰가 변경
- 네이버 블로그 게시물 작성 또는 수정
- 온라인 결제와 예약 일정 확정
- 별도 CRM 데이터베이스 구축
- 실제 서비스 실적이 없는 인증, 후기, 수치의 추가

## 12. 완료 조건

세 광고 페이지가 기존 BRING CARE 사이트 안에서 일관된 디자인으로 동작하고, 실제 블로그 현장기록을 통해 서비스 신뢰를 보여주며, 전화와 간편 견적으로 상담을 받을 수 있어야 한다. 배포 후 각 네이버 광고 캠페인에 해당 페이지 주소를 연결할 수 있는 상태를 완료로 본다.
