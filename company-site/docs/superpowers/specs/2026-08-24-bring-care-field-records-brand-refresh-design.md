# BRING CARE 현장기록·브랜드 리프레시 설계

## 목표

기존 네이버 광고용 3개 랜딩페이지의 전환 흐름을 유지하면서, BRING CARE 공식 블로그의 `브링케어 현장기록` 12건을 실제 사진과 원문 링크로 정리해 신뢰도를 높인다. 로고의 파란색을 중심으로 시각 체계를 통일하고, 블로그·카카오톡·인스타그램 접점을 명확하게 안내한다.

## 확정 방향

선택지는 모든 기록을 각 랜딩에 반복하는 방식, 건물관리 페이지만 길게 확장하는 방식, 독립 아카이브를 만들고 각 랜딩에서 연결하는 방식이다. 추천안은 세 번째다. 세 개 랜딩에는 서비스와 가까운 기록을 선별해 빠르게 보여주고, `/care-records`에서 12건 전체를 관리 유형별로 정리한다. 광고 방문자의 핵심 행동을 방해하지 않으면서도 검증 자료를 충분히 제공할 수 있기 때문이다.

## 정보 구조

- 기존 `/stair-cleaning`, `/building-care`, `/move-in-cleaning`은 현재 상담 퍼널을 유지한다.
- 각 페이지의 실제 현장기록 섹션 아래에 `현장기록 12건 전체 보기`를 추가한다.
- `/care-records`에는 12건을 `공용부 개선`, `환경 정비`, `안전·하자 점검`, `공실·임대 관리`로 묶어 노출한다.
- 각 기록 카드는 실제 현장 사진, 유형, 제목, 짧은 설명, 네이버 블로그 원문 링크를 가진다.
- 공식 채널 영역은 모든 광고 랜딩과 현장기록 페이지에서 공통으로 사용한다.

## 현장기록 원칙

- BRING CARE 공식 블로그에 게시된 실제 기록만 사용한다.
- 주소, 호수, 얼굴, 차량번호, 연락처 등 민감 정보가 보이는 사진은 제외하고 이미 가림 처리된 사진을 우선한다.
- AI 재구성 이미지와 근거가 불명확한 이미지는 사용하지 않는다.
- 결과를 과장하는 `1위`, `완벽`, `100%` 같은 표현과 확인되지 않은 실적 수치는 추가하지 않는다.
- 카드의 날짜와 설명은 게시물 제목과 공개된 현장 맥락 안에서만 작성한다.

## 브랜드 디자인

- 기본색: 로고 블루 `#1761A8`
- 짙은색: 딥 블루 `#0E3D70`
- 밝은 배경: 소프트 블루 `#EAF3FB`
- 본문색: 잉크 `#102A43`
- 기존 형광 라임의 주요 사용을 줄이고, 버튼·링크·강조·포커스를 로고 블루 계열로 통일한다.
- 로고는 헤더, 현장기록 소개, 공식 채널, 푸터에 배치하되 콘텐츠보다 먼저 보일 정도로 반복하지 않는다.
- 모바일에서 카드, CTA, 고정 상담바가 겹치지 않도록 기존 반응형 구조를 유지한다.

## 공식 채널 처리

- 네이버 블로그는 검증된 `https://blog.naver.com/bringcare`로 직접 연결한다.
- 카카오톡은 블로그에 공개된 채널명 `BRING Care`와 제공 기능(민원 접수, 상담 신청)을 안내한다. 직접 채널 URL은 확인되지 않았으므로 임의 링크를 만들지 않고 검색 방법과 전화 대안을 제공한다.
- 인스타그램은 현장 사진·소식 채널로 소개하되 공식 계정 URL이 확인될 때까지 비활성 상태로 표시한다. 허위 계정 링크보다 정확성을 우선한다.

## 추가 개선

- 현장기록마다 `청소`, `점검`, `보수`, `환경정비` 성격이 보이도록 유형 태그를 붙여 “청소하면서 건물까지 봅니다”를 증명한다.
- 각 기록 카드에서 블로그 원문으로 나가기 전에 동일 사이트 내 상담 CTA를 자연스럽게 연결한다.
- 아카이브 상단에는 12건, 4개 관리 유형, 원주 현장 기록이라는 탐색 요약을 제공한다.
- 정적 내보내기와 Firebase 배포 대상에 `/care-records`를 포함한다.

## 완료 기준

- 12개 게시물 URL이 중복 없이 모두 데이터에 존재한다.
- 모든 사용 사진이 로컬에서 정상 해석되고 크기·용량 제한을 통과한다.
- 3개 기존 랜딩과 새 아카이브가 데스크톱·모바일에서 정상 렌더링된다.
- 네이버 블로그 외 검증되지 않은 소셜 직접 URL이 없다.
- 테스트, 빌드, 정적 내보내기, 운영 배포와 운영 URL 확인이 완료된다.
