## 1. 목표

TV에 연결된 Windows 컴퓨터에서 회사 운영보드를 전체화면으로 띄우고, Windows 로그인 후 자동 실행되도록 구성한다. 운영보드 화면과 데이터는 서버에서 갱신되어 TV 컴퓨터를 매번 조작하지 않는 상태가 최종 목표다.

## 3. 지금까지 진행한 내용

### 서버·화면

- Cloudflare Worker의 `/tv` 공개 화면을 사용한다.
- TV 화면은 회사 운영보드의 프로젝트 로드맵·담당자 성과·일정 등을 자동 순환하도록 개발했다.
- TV 등록 전에는 등록코드를 표시하고, 승인 후 회사 데이터를 읽는 구조다.
- 과거에 표시된 등록코드는 재사용하지 말고 TV 화면에 현재 표시되는 코드를 사용해야 한다.

### 설치판 v1.0.4

이전 설치 과정에서 실패가 반복되어 별도 스크립트 엔진 호출을 제거하고 Windows CMD만 사용하는 설치판을 새로 만들었다.

ZIP 구성은 다음 6개 파일로 고정했다.

1. `BRING-TV-설치.cmd`
2. `BRING-TV-자동실행.cmd`
3. `BRING-TV-삭제.cmd`
4. `사용방법.txt`
5. `BRING-TV-설치복구-프롬프트.txt`
6. `README.md`

설치파일의 의도된 동작은 다음과 같다.

1. Edge 또는 Chrome 설치 여부 확인
2. 현재 Windows 사용자의 시작프로그램 폴더 확인
3. `BRING-TV-자동실행.cmd`만 시작프로그램 폴더에 복사
4. 설치 직후 TV 운영보드 실행
5. 다음 Windows 로그인부터 자동 실행
6. `%LOCALAPPDATA%\BRING-TV\BrowserProfile`을 계속 사용해 TV 등록정보 유지

삭제파일은 시작프로그램의 `BRING-TV-자동실행.cmd`만 삭제한다. 브라우저 프로필·쿠키·TV 등록정보·CRM 데이터는 삭제하지 않는다.

## 5. 현재 장애 상태

사용자 보고는 “계속 안 된다”, “PowerShell을 넣으면 실패한다”, “프로그램을 다운로드할 수 없다”였다. v1.0.4에서는 PowerShell 단계를 제거했지만 실제 TV 컴퓨터의 최신 오류 화면이나 오류 기록을 아직 확보하지 못했다.

현재는 다음 중 어느 단계에서 실패하는지 확정되지 않았다.

| 구분 | 화면·증상 | 다음 확인자료 |
| --- | --- | --- |
| 다운로드 실패 | 브라우저에서 파일 차단 또는 다운로드 실패 | 브라우저 다운로드 목록 화면 |
| 압축 해제 실패 | ZIP을 열 수 없거나 파일명이 깨짐 | 압축 해제 폴더 전체 화면 |
| CMD 실행 실패 | 더블클릭해도 창이 즉시 닫히거나 보안 경고 | 바탕화면 오류파일과 CMD 실행 화면 |
| 브라우저 실행 실패 | 설치 완료 후 운영보드가 열리지 않음 | Edge·Chrome 설치 경로와 오류파일 |
| 등록 대기 | 운영보드 대신 등록코드만 표시 | 현재 등록코드와 CRM TV 승인 화면 |
| 승인 후 데이터 실패 | 승인했지만 빈 화면 또는 연결 확인만 반복 | TV 화면·브라우저 개발자 콘솔·서버 로그 |
| 자동실행 실패 | 수동 실행은 되지만 재로그인 후 열리지 않음 | 시작프로그램 폴더와 작업 관리자 시작프로그램 화면 |

## 6. 다음 담당자의 첫 점검 순서

다음 순서를 바꾸지 말고, 실패 단계가 확인된 뒤에만 코드를 수정한다.

1. TV 컴퓨터에서 운영보드 주소를 Edge로 직접 연다.
2. 화면이 열리면 서버·인터넷은 정상으로 분리한다.
3. 직접 다운로드 링크를 Edge 주소창에 붙여 ZIP을 받는다.
4. 다운로드 목록에서 차단·삭제·실패 표시를 확인한다.
5. ZIP 전체를 새 로컬 폴더에 압축 해제한다. ZIP 내부에서 바로 실행하지 않는다.
6. 압축 해제된 6개 파일이 모두 보이는지 확인한다.
7. `BRING-TV-설치.cmd`를 더블클릭한다.
8. 실패하면 바탕화면의 `BRING-TV-CMD-설치-오류.txt`를 확보한다.
9. 오류파일이 없으면 명령 프롬프트에서 아래처럼 실행해 종료코드를 확보한다.

```bat
cd /d "압축을_푼_폴더_경로"
call "BRING-TV-설치.cmd"
echo EXITCODE=%ERRORLEVEL%
```

10. 운영보드가 열리고 등록코드가 표시되면 설치 실패가 아니라 **TV 등록 승인 대기 상태**로 분류한다.
11. CRM의 TV 관리 화면에서 현재 코드를 승인한다.
12. 데이터 표시, 자동 화면 전환, 재로그인 후 자동 실행을 각각 확인한다.

## 7. 다음 담당자가 반드시 받아야 할 증빙

- TV 컴퓨터 Windows 버전
- Edge 또는 Chrome 버전
- 다운로드 목록 화면
- 압축 해제 폴더 전체 화면
- 실패 직후 CMD 창 화면
- `BRING-TV-CMD-설치-오류.txt` 원문
- 현재 TV 등록코드 화면
- CRM에서 해당 코드 승인 여부
- 승인 후 TV 화면
- 재로그인 후 자동 실행 여부

비밀번호, 인증코드, 쿠키, API 키, 개인 브라우저 자료는 받지 않는다.

## 8. 우선 의심할 원인

현장 증빙이 없으므로 아래는 확정 원인이 아니라 확인 우선순위다.

1. 브라우저 또는 Windows 보안 기능이 실행파일이 포함된 ZIP 다운로드를 차단
2. ZIP 내부에서 CMD를 직접 실행해 함께 있는 자동실행 파일을 찾지 못함
3. 회사 보안 프로그램이 CMD 실행이나 시작프로그램 폴더 쓰기를 차단
4. Edge·Chrome이 표준 경로가 아닌 다른 위치에 설치됨
5. 설치는 됐지만 TV 등록 승인이 되지 않아 등록코드 화면만 표시됨
6. 승인 데이터가 다른 회사·계정 범위에 저장되어 TV가 읽지 못함

## 9. 임시 운영 방법

설치 자동화가 해결되기 전에는 TV 컴퓨터의 Edge에서 아래 주소를 직접 열고 `F11`로 전체화면을 사용할 수 있다.

<https://bring-crm-ai-gateway.bringengineering1008.workers.dev/tv>

이 방법은 화면 확인용이며 Windows 재시작 후 자동 실행까지 보장하지 않는다.

## 10. 수정 시 지켜야 할 기준

- 기존 CRM·TV 서버 데이터와 등록정보를 삭제하지 않는다.
- 기존 릴리스 태그를 이동하거나 재사용하지 않는다.
- 수정판은 `v1.0.5`처럼 새 버전으로 배포한다.
- 먼저 실제 실패를 재현하는 검증을 추가하고 수정한다.
- 현장 TV에서 다운로드 → 압축 해제 → 설치 → 승인 → 데이터 표시 → 재로그인 자동실행까지 검증하기 전에는 완료 처리하지 않는다.
- 공개 파일은 로컬 파일과 SHA-256을 대조한다.
- 사용자에게 보내는 메일에는 직접 다운로드 링크와 정확한 버전을 기재한다.
