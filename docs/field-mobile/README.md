## 만들 제품

회사 직원이 Android·iPhone에서 현장을 선택하고 전·중·후 사진을 찍으면 회사 Google Drive의 활동사진에 정리한다. 같은 앱에서 작업 결과보고서를 검토하고 PDF를 보관하며, 관리자 권한으로 고객 알림톡 발송과 전달 결과 확인까지 마친다. PC CRM을 켜 놓거나 현장에서 다시 자료를 옮기지 않는 것이 완료 기준이다.

사용자가 확인한 범위는 **우리 회사 직원 전용**이다. 공개 고객 가입, 협력업체 가입, 고객용 앱은 포함하지 않는다. 2026-10-26 화면 미리보기 승인 후 구성·설계를 진행했으며, 이 문서는 기능 구현이나 스토어 출시가 완료됐다는 뜻이 아니다.

## 첫 버전과 후속 범위

첫 버전의 필수 완성 구간은 **현장 선택 → 사진 → 작업 결과보고서 PDF → CRM 연결 → 고객 알림톡 전달 확인**이다. 사진첩에서 선택한 작업사진 추가, 구역·전중후 수정, 중단 복구도 포함한다.

월간보고서는 이번 촬영·작업 기록을 기존 CRM 집계에 연결하는 데까지 첫 버전에 포함한다. 모바일에서 월간 집계·초안·PDF·발송을 직접 수행하는 화면은 후속 단계로 분리한다. 기존 CRM 월간보고서 기능과 실제 수신 요청 검증은 유지한다. 자동 정기 발송, 영상, 광고·부동산 매물, 결제, 근태·위치 추적은 첫 버전 범위가 아니다.

## 중요한 발견

기존 CRM에 보고서·사진·수신자 연결, PDF 무결성 확인, 승인 템플릿 확인, 발송 상태 관리가 있다. 그러나 일부 중요한 처리는 Electron main process와 `printToPDF`에 묶여 있다. 화면만 휴대폰으로 옮기면 PC 없이 완료할 수 없으므로 **보안 API와 서버 PDF·보관 작업자**를 함께 개발해야 한다.

과거 BRING FIELD 웹앱은 매물·광고용 촬영 구조도 포함한다. 그 큐·Drive 처리에서 검증된 개념을 참고하되, 이번 앱의 작업사진을 광고 매물 폴더나 고객과 무관한 경로에 저장하지 않는다.
