# Reference Library

참고자료는 아래 하위 폴더로 분류한다.

- `Before_After`: 동일 화각 전후 비교 참고
- `Price`: 가격표·가격 설명 방식
- `Cleaning`: 작업범위·과정 표현
- `Shortform`: Reels·Shorts 구조
- `Competitor`: 경쟁사 공개소재와 관찰일
- `Overseas`: 해외 시설관리·청소 브랜드
- `Copy`: 제목·CTA·고객 질문 표현

파일명: `YYYYMMDD_출처_주제_설명.ext`

참고자료는 그대로 복제하지 않고 `좋은 점 / 위험요소 / 브링케어 적용안`을 README 또는 같은 이름의 메모에 남긴다.
