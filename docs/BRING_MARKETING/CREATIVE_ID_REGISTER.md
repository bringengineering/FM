# BRING CARE Creative ID 등록대장

## 발급 규칙

- 형식: `CR-0001`부터 순차 증가
- 하나의 핵심 메시지·영상·이미지 조합마다 하나의 ID
- 단순 오탈자 수정은 버전 증가, 메시지·후킹·주요 이미지 변경은 새 ID 발급
- 삭제하지 않고 상태를 `초안 / 승인 / 집행중 / 중지 / 우수소재 / 보관`으로 변경

## 등록대장

|---|---|---|---|---|---|---|---|---|---|---:|---:|---:|---:|---:|---:|---|

## CRM 연결

1. 홈페이지·광고 링크의 `utm_content`에 Creative ID를 넣는다.
2. Lead 접수 시 `utmContent/Creative ID`를 보존한다.
3. 주문 전환 시 Lead ID와 Creative ID를 주문에 연결한다.
4. 결제·환불·원가를 반영해 Creative별 공헌이익을 계산한다.
5. 주간 리뷰에서 중지·확대·재제작을 결정한다.
