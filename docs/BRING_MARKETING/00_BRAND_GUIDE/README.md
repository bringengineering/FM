# BRING CARE 브랜드 가이드

## 핵심 메시지

- 현장 추가금 없음
- 브링케어 책임검수
- 문제 발생 시 브링케어 단일창구
- 단순 청소가 아니라 건물 운영의 시작

## 시각 원칙

- 대표·상담·현장 책임자는 정장 사진을 핵심 신뢰자산으로 사용한다.
- 실제 현장사진은 과도한 보정 없이 오염과 결과가 명확하게 보이도록 한다.
- Before와 After는 같은 위치·방향·화각으로 촬영한다.
- 고객 개인정보, 주소, 얼굴, 차량번호는 동의 없이 노출하지 않는다.

## 금지 표현

- 확인되지 않은 업계 1위·최저가·완벽·100% 보장
- 현장 상황과 다른 연출 사진을 실제 작업 증거처럼 표시
- 사전 합의 없이 추가금이 생길 수 있다는 표현
