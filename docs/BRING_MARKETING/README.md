# BRING CARE Marketing Reference Library

이 폴더는 광고파일 창고가 아니라 `현장 증거 → Creative → Lead → 계약 → 공헌이익`을 연결하는 운영체계다.

## 사용 순서

1. 실제 현장 원본을 `02_RAW` 규칙으로 정리한다.
2. 사용 동의를 확인한다.
3. `CREATIVE_ID_REGISTER.md`에서 ID를 발급한다.
4. 편집본과 광고 관리자 이름에 같은 ID를 쓴다.
5. 랜딩 링크 `utm_content`에도 같은 ID를 쓴다.
6. CRM Lead와 주문에서 해당 ID를 유지한다.
7. `07_PERFORMANCE`에서 주간 성과를 집계한다.
8. 검증된 소재만 `08_BEST_CREATIVE`에 보관한다.

## 오픈 전 채워야 할 최소수량

- Before/After 20세트
- 현장 Raw 사진 100장 이상
- 세로영상 30개 이상
- Reels/Shorts 10개 이상
- 가격형·Before/After·문제형·신뢰형·실제현장 소재 각 5개
