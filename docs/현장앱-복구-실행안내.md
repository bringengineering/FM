`firebase-target-manifest.test.ts` 가 이 분리를 검사하고 있다. 인스턴스

# 2. 계정 등록

`fieldPlatformAllowedEmails` 에 등록된 이메일만 로그인할 수 있다. 이 목록에
값을 넣는 코드는 저장소 어디에도 없다 — 사람이 등록해야 한다.

```
gcloud auth application-default login
```

**`dpvld858@gmail.com`** 을 고른다. 회사 계정을 고르면 권한 오류가 난다.

```
cd /d C:\bring
node functions\scripts\bootstrap-field-account.mjs --email=등록할주소@gmail.com --role=admin
```

무엇을 어디에 쓸지 먼저 보여 준다. 맞으면 `--yes` 를 붙여 다시 실행한다.

- 역할은 `admin`, `staff`, `reviewer`
- **v1 을 쓰는 동안은 `admin` 또는 `reviewer` 로 등록한다.** `staff` 는 사진
  열람·제외가 함수 경로로 되돌아간다
- 회수는 `--mode=revoke`. 이미 발급된 토큰은 최대 1시간 남으므로 즉시
  끊으려면 Firebase 콘솔 > Authentication 에서 계정을 사용 중지한다

# 3. 구글 드라이브 연결 (한 번만)

함수 배포 시 `DRIVE_*` 비밀값 5개를 요구한다. 실제로 그 값을 쓰는 함수는
`retiredLegacy` 쪽 4개뿐이지만, firebase 는 코드베이스 전체의 비밀값을 먼저
확인하기 때문에 **배포하려면 있어야 한다.**

1. **OAuth 클라이언트** — https://console.cloud.google.com/apis/credentials?project=bring-fm
   → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → **데스크톱 앱**
2. **Drive API 켜기** — https://console.cloud.google.com/apis/library/drive.googleapis.com?project=bring-fm
3. **Secret Manager API 켜기** — https://console.developers.google.com/apis/api/secretmanager.googleapis.com/overview?project=bring-fm

여기까지는 `dpvld858` 로 한다. 그다음:

```
cd /d C:\bring
set GOOGLE_DRIVE_OAUTH_CLIENT_ID=발급받은ID
set GOOGLE_DRIVE_OAUTH_CLIENT_SECRET=발급받은Secret
set GOOGLE_DRIVE_OAUTH_REDIRECT_URI=http://127.0.0.1:53682/oauth2callback
node functions\scripts\google-drive-oauth.mjs
```

> 환경변수로 넘기는 이유는 스크립트의 가려진 입력창이 붙여넣기를 자주
> 놓치기 때문이다. 값이 그 창의 기록에 남으므로 **작업이 끝나면 창을 닫는다.**

긴 권한 URL 이 나오면 브라우저에서 열고 **`bringengineering1008@gmail.com`**
으로 동의한다. `127.0.0.1` 페이지가 열리지 않는 것이 정상이며, 주소창의 URL
전체를 복사해 붙여넣는다.

끝나면 `DRIVE_REFRESH_TOKEN` 과 폴더 ID 를 **한 번만** 보여 준다. 먼저 복사해
둔 뒤 아래를 하나씩 실행한다. **명령을 먼저 실행하고, 값을 물어보면 그때
붙여넣는다.** 명령 뒤에 값을 같이 붙이면 그 값을 비밀값 이름으로 읽는다.

```
firebase functions:secrets:set DRIVE_CLIENT_ID
firebase functions:secrets:set DRIVE_CLIENT_SECRET
firebase functions:secrets:set DRIVE_REFRESH_TOKEN
firebase functions:secrets:set DRIVE_ROOT_FOLDER_ID
firebase functions:secrets:set DRIVE_ROOT_MODE
```

`DRIVE_ROOT_MODE` 는 `appCreated` 로 입력한다. 이 모드는 `drive.file` 권한만
쓰므로 앱이 만든 파일 외에는 접근하지 않는다.

현장앱은 reCAPTCHA Enterprise 로 App Check 토큰을 받는다. 사이트 키가 없으면
**"현장 업무 연결 확인 필요 / 보안 연결을 확인하지 못했습니다"** 에서 멈춘다.

1. 키 만들기 — https://console.cloud.google.com/security/recaptcha?project=bring-fm
   플랫폼 **웹사이트**, 도메인에 `bring-fm.web.app` 과 `bring-fm.firebaseapp.com`

`NEXT_PUBLIC_FIREBASE_APPCHECK_SITE_KEY` 가 있으면 그쪽이 이긴다.

# v2 를 켤 때

현재 진입점은 v1 이다. v2 는 데이터베이스에 세 가지가 있어야 동작한다.

| 경로 | 내용 | 없으면 |
| --- | --- | --- |
| `fieldPlatform/v2/config/release` | `protocolVersion: 2`, `minPwaVersion`, `minDesktopVersion`, `enabledOperatorIds`, `v2WritesEnabled`, `canonicalCrmEnabled`, `safeMode`, `cutoverAt` | `field_release_config_invalid` |
| `crmCompany/access/{authUid}` | CRM 계정 — 로그인 이메일과 일치해야 함 | `field_access_forbidden` |
| `crmCompany/teamProfiles/{operatorId}` | 담당자 프로필 (`active: true`) | `field_operator_invalid` |

**v2 는 현장앱을 CRM 계정 체계에 묶는다.** 현장앱이 받는 계정과 CRM 사용자
계정을 어떻게 연결할지 정해야 한다. 사람이 정할 문제라 코드로 정하지 않았다.

정해지면 `app/field/page.tsx` 의 한 줄을 `FieldV2App` 으로 되돌린다.
`field-v2-entry.test.ts` 가 지금 진입점이 무엇인지, 그리고 v2 코드가 그대로
보존되어 있는지 함께 검사한다.

v1 로 쓰는 동안 되는 것과 안 되는 것:

| | v1 (지금) | v2 |
| --- | --- | --- |
| 건물·호실·매물 등록 | 됨 | 됨 |
| 촬영·드라이브 업로드 | 됨 | 됨 |
| 소유자 메모·광고 패키지 | 됨 | 됨 |
| 작업 배정·전환·방문 변경 | **없음** | 됨 |
| 데스크톱 CRM 인계 | **없음** | 됨 |

데스크톱 CRM 쪽 현장 업무 임베드는 별도로 꺼져 있다
(`desktop-crm/src/main.js` 의 `FIELD_OPERATIONS_ENABLED = false`).

# 앱으로 만들 것인가

현장앱은 이미 PWA 다. 홈 화면에 추가하면 아이콘이 생기고 주소창 없이 뜬다.
오프라인 동작(`FieldServiceWorker`)과 업로드 대기열(`offline-queue.ts`)도 들어
있다.

스토어 앱은 고칠 때마다 심사를 기다려야 하고 직원이 각자 업데이트해야 한다.
사내 도구에는 손해가 크다. **백그라운드 대용량 업로드나 푸시 알림이 실제로
필요해지면** 그때 검토한다.

# 건드리지 말 것

- `release/firebase-targets.json` 의 `functionsDeploymentAllowed: false`
  — 자동 릴리스가 함수를 배포하지 못하게 막는 장치다. `readAutomaticFirebaseTarget`
  이 코드로 검증한다
- CI 신원의 함수 배포 권한 — `bootstrap-bring-fm-wif.ps1` 이 명시적으로 금지한다
- `retiredLegacy` 함수들의 `instance: "bring-fm-hj-default-rtdb"`

# 채팅에 붙여넣지 말 것

- `firebase login:ci` 토큰, 서비스 계정 키(JSON), 구글 계정 비밀번호
- **OAuth 클라이언트 보안 비밀번호**(`GOCSPX-…`), **`DRIVE_REFRESH_TOKEN`**(`1//…`)

reCAPTCHA 사이트 키와 OAuth 클라이언트 ID 는 공개 값이라 괜찮다.
막히면 **에러 문구만** 전달한다.
