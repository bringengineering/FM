# CRM 수기 견적서 설계

## 목표
기존 AI 견적을 유지하면서 AI 호출 없이 빈 견적서를 직접 작성하고 기존 공급자·인감·Excel/PDF 출력 기능을 그대로 사용한다.

## 화면과 흐름
- 견적서 작성 화면에 `AI 작성`과 `수기 작성` 전환을 둔다.
- 수기 작성은 빈 견적명, 공급받는자, 전화번호, 품목 1행으로 시작한다.
- 견적명·성명·전화번호와 품목명·상세·금액을 직접 수정하며 합계·공급가액·부가세는 즉시 재계산한다.
- AI 빠른 예시와 AI 생성 버튼은 AI 작성 모드에서만 보인다.
- 기존 공급자 보관용·공급받는자용 Excel/PDF 출력 계약은 변경하지 않는다.

## 오류와 검증
- 품목은 항상 1개 이상이며 금액이 0인 상태에서는 파일 출력을 막고 입력 안내를 보여준다.
- AI API는 수기 작성 경로에서 호출하지 않는다.
- 기존 AI 견적 테스트와 수기 견적 생성·편집·출력 활성화 테스트를 함께 실행한다.
