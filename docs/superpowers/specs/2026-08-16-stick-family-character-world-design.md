# 생활경제 졸라맨 세계관 디자인

## 목적

생활경제·소비·직장·보험·대출·자영업 정보를 고정 등장인물의 일상 이야기로 설명한다. 영상은 한국 생활 시트콤의 공간 구성과 완전한 졸라맨 캐릭터를 결합한다. 시청자가 캐릭터의 상황에 먼저 공감한 뒤, 생활 공간이 간단한 원리 도식으로 변하면서 정보를 이해하도록 설계한다.

## 기본 영상 문법

1. 내레이터가 `어디에 사는 몇 살 누구인데요`로 주인공을 소개한다.
2. 아파트·주택·가게 외관에서 창문이나 출입문을 거쳐 생활 공간으로 들어간다.
3. 고정 캐릭터가 휴대폰, 영수증, 가방, 열쇠 같은 소품을 통해 문제를 발견한다.
4. 캐릭터의 선택을 따라가며 갈등을 키운다.
5. 필요한 순간에만 생활 공간이 계산·비교·흐름 도식으로 단순하게 변한다.
6. 원리 설명 후 같은 생활 공간으로 돌아와 조건부 행동 사례를 제시한다.

생활 시트콤 장면이 약 70%, 원리 설명 장면이 약 30%를 차지한다.

## 공통 그림 규칙

- 머리는 검은 외곽선의 흰색 원이다.
- 몸통은 캐릭터 기준색의 한 줄이다.
- 팔과 다리는 검은 단선이다.
- 손은 생략하거나 작은 원으로만 표현한다.
- 발은 짧은 선으로 표현할 수 있다.
- 코, 귀, 손가락, 근육, 사실적인 관절은 그리지 않는다.
- 평소 얼굴에는 눈과 입을 표시하지 않는다.
- 감정이 필요한 짧은 순간에만 점눈 두 개, 짧은 입, 눈썹을 표시한다.
- 감정이 끝나면 다시 무표정의 빈 얼굴로 돌아간다.
- 땀방울, 느낌표, 진동선, 속도선은 한 장면에 하나만 사용한다.
- 4명의 기본 키는 같고, 동현만 최대 5% 크게 표현할 수 있다.
- 동일 인물의 머리 크기, 몸통 길이, 식별 소품은 모든 영상에서 유지한다.

## 배경과 카메라

- 배경은 파스텔 색상의 단순한 2D 한국 생활 공간이다.
- 민지의 거실은 회색 소파, 낮은 나무 탁자, 장스탠드, 크림색 커튼, 벽시계, 오른쪽 주방 출입구로 고정한다.
- 배경은 캐릭터보다 가는 선 또는 낮은 대비로 그린다.
- 기본 진입은 `외관 → 창문/문 → 생활 공간 → 캐릭터 중경` 순서다.
- 생성 안정성을 위해 한 영상 클립은 기본적으로 2~3개의 명확한 컷으로 구성한다.
- 휴대폰 화면은 실제 앱이 아니라 추상 색 블록과 진행 막대로 표현한다.
- 한글과 정확한 숫자는 생성 영상이 아니라 편집에서 넣는다.

## 금지 요소

- 특정 기존 애니메이션의 캐릭터, 얼굴, 배경, 색채를 직접 복제하지 않는다.
- 사실적인 사람, 3D 인물, 손가락, 상세한 얼굴을 만들지 않는다.
- 캐릭터의 몸통색과 식별 소품을 장면 중간에 바꾸지 않는다.
- 한 캐릭터에게 다른 캐릭터의 안경·머리표식·소품을 붙이지 않는다.
- 생성 영상에 실제 카드사·은행·쇼핑몰 UI와 브랜드를 넣지 않는다.
- 표정은 상시 유지하지 않으며 감정 순간에만 잠깐 사용한다.

## 첫 적용 영상

- 주제: 카드 실적이 3만 원 남았을 때
- 주인공: 김민지
- 시작: 성남의 아파트 외관 → 창문 → 고정 거실 → 소파에서 휴대폰을 확인하는 민지
- 사건: 카드 실적이 3만 원 남았고 다음 달 2만 원 혜택이 걸려 있음
- 시각 방식: 민지의 생활 이야기로 시작하고, 거실 물건과 카드 진행 막대가 계산 도식으로 전환됨
- 결말: 원래 살 물건 세 개를 먼저 적는 구체적인 사례

## 제작 검증

- 생성 전 각 캐릭터 공식 이미지를 이미지 레퍼런스로 첨부한다.
- 첫 프레임과 마지막 프레임에서 몸통색과 소품을 비교한다.
- 얼굴이 필요한 장면인지 프롬프트에 명시하고, 아니라면 빈 얼굴을 요구한다.
- 민지 장면은 코랄 몸통, 머리 선 두 개, 작은 가방 중 최소 두 요소가 보여야 한다.
- 장면 1 시안 승인 후 같은 아파트와 민지를 다음 장면의 이미지 레퍼런스로 사용한다.
