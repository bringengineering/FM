# 브링케어 계단·공용부 청소 레퍼런스 강화 설계

## 목적

계단·공용부 청소 광고 페이지에서 브링케어의 실제 수행 역량을 빠르게 이해하게 한다. 타사 유튜브 영상은 작업 구도와 설명 순서를 참고하는 용도로만 사용하며, 타사 장면이나 AI 제작 이미지를 브링케어의 실제 실적으로 표시하지 않는다.

## 콘텐츠 구조

페이지의 레퍼런스 영역을 두 종류로 명확히 분리한다.

1. **서비스 작업 범위**
   - 브링케어 유니폼을 적용해 제작한 작업 이미지 사용
   - 계단 바닥, 모서리·틈새, 난간, 공동현관, 공용창·창틀, 안전설비 주변으로 세분화
   - 유튜브 자료에서 참고한 작업 순서와 구도를 활용하되 영상 캡처나 타사 상표는 사용하지 않음
   - 실제 수행 실적으로 오인할 수 있는 `현장 실적`, `고객 사례` 표현은 사용하지 않음

2. **BRING CARE 실제 관리 기록**
   - 브링케어가 직접 수행하고 원문으로 확인 가능한 사진만 사용
   - 각 사례를 `확인한 문제 → 진행한 조치 → 관리 결과` 순서로 설명
   - 네이버 블로그 원문 링크를 제공해 검증 가능하게 구성
   - 기존 실제 기록 4건을 우선 활용: 공용부 환경 정비, 벽면 하자 확인, 전기 화재예방 조치, 건물 입구 안내환경 개선

## 화면 구성

- 실제 관리 기록 섹션 제목: `말보다 현장으로 보여드립니다.`
- 섹션 소개에서 실제 수행 사진과 서비스 설명용 이미지의 차이를 한 문장으로 안내
- 실제 사례 카드는 사진, 현장 유형, 문제·조치·결과, 원문 링크로 구성
- 모바일에서는 한 열로 배치하고 사진을 충분히 크게 노출
- 기존 토스형 타이포그래피, 여백, 둥근 카드 스타일을 유지

## 신뢰 및 광고 기준

- 타사 유튜브 캡처를 브링케어 소유 사진처럼 게시하지 않음
- AI 또는 합성 이미지에 `실제 현장` 배지를 사용하지 않음
- 실제 기록에는 확인 가능한 원문 링크를 유지
- 수치·계약 건수·만족도처럼 검증되지 않은 실적은 추가하지 않음

## 검증 기준

- 서비스 이미지와 실제 관리 기록이 제목과 문구로 구분되어야 함
- 실제 사례 4건 모두 문제·조치·결과 설명과 원문 링크를 가져야 함
- 데스크톱과 모바일에서 이미지 및 문구가 잘리거나 겹치지 않아야 함
- 기존 견적 신청과 전화·카카오 상담 동선이 유지되어야 함
- 랜딩 페이지 테스트, 프로덕션 빌드, Firebase 내보내기 및 공개 URL 확인을 통과해야 함
