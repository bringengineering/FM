# 건물관리 광고 페이지 시각 명료화 설계

## 목표

기존 건물관리 광고 페이지의 구조와 디자인을 유지하면서, 첫 화면에서 BRING CARE의 정체성을 먼저 보여주고 문제·관리 흐름을 시각적으로 즉시 이해시키도록 개선한다.

## 확정 범위

1. `BRING CARE MANAGEMENT TEAM` 계단 단체 장면을 페이지 최상단에 배치한다.
2. 기존 가격·공실 히어로는 단체 장면 다음에 유지한다.
3. 페이지 내 1인칭 표현은 `우리` 대신 `저희` 또는 `BRING CARE`로 통일한다.
4. 고객 문제 3개 카드에 업무 의미가 분명한 아이콘을 추가한다.
   - 공실·퇴실: 문과 이동
   - 시설·민원: 공구와 대화
   - 결과 확인: 체크리스트와 기록
5. `확인 → 조율 → 처리 → 기록` 관리 흐름의 무관한 기존 사진을 제거한다.
6. 네 장면 모두 동일한 시각 문법의 자연스러운 실사형 AI 이미지로 교체한다.
   - 확인: 정장 차림 관리자가 공실 내부를 태블릿으로 확인
   - 조율: 정장 차림 관리자가 전화와 일정표로 업체 일정을 조율
   - 처리: 현장 작업자와 정장 관리자가 수리 완료 상태를 확인
   - 기록: 정장 차림 관리자가 태블릿에 완료 사진과 보고서를 정리
7. 생성 이미지는 브랜드 캠페인 장면으로 사용하며 실제 현장 기록이라고 오인시키는 대체텍스트를 사용하지 않는다.

## 디자인 원칙

- 토스형 큰 제목, 넓은 여백, 파란색 강조, 둥근 카드와 얕은 그림자를 유지한다.
- 아이콘은 이모지가 아닌 단색 선형 SVG로 통일한다.
- 관리 흐름 사진은 동일한 인물·의상·색감으로 연속성이 느껴지게 한다.
- 기존 실제 관리사례 섹션은 실사 증거로 유지하고 AI 이미지로 교체하지 않는다.

## 검증

- 단체 계단 장면이 첫 번째 주요 섹션인지 자동 테스트한다.
- 문제 카드 3개에 아이콘이 존재하는지 테스트한다.
- 관리 흐름 이미지가 새 전용 자산 4개를 사용하는지 테스트한다.
- 페이지에서 `우리` 단독 표현이 제거되었는지 테스트한다.
- 전체 랜딩 테스트, 프로덕션 빌드, 공개 URL 검수를 수행한다.
