# 입주청소·건물 공용부 청소 광고 페이지 분리 설계

## 목표

현재 계단·공용부 페이지에 섞여 있는 입주청소 연출 이미지를 입주청소 전용 페이지로 옮기고, 계단·공용부 페이지에는 해당 서비스와 직접 관련된 현장 사진만 사용한다. 두 페이지는 동일한 BRING CARE 토스형 디자인을 유지하되 검색 의도, 가격, 문구, 견적 신청 유형을 완전히 분리한다.

## 페이지 구성

### `/move-in-cleaning`

- 첫 화면: BRING CARE 유니폼을 입은 작업자의 입주청소 장면
- 핵심 문구: 새 공간의 첫날을 위한 입주·이사청소
- 작업 범위: 창문·창틀, 욕실·배수구, 주방·후드, 수납장, 바닥·모서리, 환기구
- 이미지: 기존에 제작한 BRING CARE 서비스 연출 이미지 9종
- 이미지 표기: 실제 시공 실적과 혼동되지 않도록 `브링케어 서비스 연출 이미지` 표시
- 가격: 일반 단건 입·퇴실청소 12만원부터, 관리 건물 입·퇴실청소 10만원부터, 부가세 별도
- 견적 전송값: `입주·이사청소`, `/move-in-cleaning`
- 실제 기록: 입주·공실·입퇴실 관리와 직접 관련된 검증된 기록만 노출

### `/stair-cleaning`

- 첫 화면: 실제 건물 공동현관 또는 계단·복도 사진
- 핵심 문구: 계단청소를 넘어 건물의 첫인상을 관리
- 작업 범위: 계단·난간, 복도·승강기 홀, 공동현관, 공용창·창틀
- 이미지: 첨부 구도를 참고해 새로 제작한 BRING CARE 네이비 유니폼의 계단·공용부 청소 연출 이미지 5종
- 연출 장면: 계단 밀대 청소, 계단 모서리 브러시 작업, 계단 하행 청소, 소화기 주변 정리, 공용창 청소
- 이미지 표기: `브링케어 서비스 연출 이미지`를 표시하고 실제 관리 실적과 별도 구역에 배치
- 입주청소 이미지 제거: 욕실, 주방, 수납장 등 입주청소 전용 장면은 노출하지 않음
- 운영 정보: 월 4회 정기방문, 주 2·3회 협의 가능, 월간 관리보고, 시설 상태 확인, 원주 직영팀
- 가격: 3층 6만원, 4층 7만원, 5층 8만원부터, 부가세 별도
- 견적 전송값: `계단·공용부 청소`, `/stair-cleaning`
- 실제 기록: 공용부 환경 정비, 벽면 하자 확인, 전기 화재예방 조치, 건물 입구 안내환경 개선

## 공통 디자인

- 현재 승인된 토스형 밝은 배경, 큰 제목, 넉넉한 여백, 둥근 카드 스타일 유지
- PC와 모바일에서 이미지가 과도하게 잘리지 않도록 카드별 이미지 비율과 `object-position`을 조정
- 상단과 하단에 견적 CTA를 유지하고, 견적 폼은 페이지 안에서 바로 작성 가능하게 제공
- 전화 `010-6566-3603`과 카카오톡 채널 상담을 유지
- 모든 가격에 부가세 별도 안내

## 데이터와 안전성

- 기존 CRM 전송 방식을 재사용하며 서비스명과 유입 경로만 페이지별로 구분
- 실제 현장 사진과 연출 이미지를 명확히 구분해 허위 시공 실적으로 오인되지 않게 함
- 기존 관리 실적 링크는 검증된 네이버 블로그 원문만 연결

## 검증 기준

- 입주청소 페이지에 공용부 관리 실적이나 월간 정기청소 가격이 섞이지 않는다.
- 계단·공용부 페이지에 욕실·주방·수납장 입주청소 이미지가 남지 않는다.
- 두 페이지의 견적 폼이 각각 올바른 서비스명과 유입 경로를 전송한다.
- 모바일과 PC에서 핵심 이미지가 잘리지 않고 견적 신청 영역이 표시된다.
- 테스트, 정적 빌드, 실제 배포 URL 확인을 모두 통과한다.
