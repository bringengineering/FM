# 브링케어 청소기 필터 글 전면 재작성 설계

## 목표

공개 글 `청소기 필터 교체 주기, 날짜보다 먼저 볼 세 가지 신호`를 얕은 생활상식 요약이 아닌 실전 판별형 콘텐츠로 전면 재작성한다. 독자가 글을 읽은 뒤 현재 필요한 조치를 `청소`, `완전 건조`, `교체`, `전문 점검` 가운데 하나로 구분할 수 있어야 한다.

## 콘텐츠 역할

- 콘텐츠 엔진: `traffic`
- 배포 목표: 네이버 검색과 홈피드 혼합
- 핵심 검색 의도: 청소기 필터 교체 시기와 상태 판단
- 최종 행동: 저장
- 금지 요소: 브링케어 회사소개, 상담 문단, 상담 CTA, 상담 배너, 승인되지 않은 제휴 링크

## 편집 방향

실전 판별 정보를 70%, 공감 가능한 생활 장면을 30%로 구성한다. 제공되지 않은 사용 경험이나 현장 사례는 만들지 않는다. 첫 도입은 청소 후에도 먼지가 남는 상황과 답답함으로 시작하되, 특정 제품을 직접 사용했다고 주장하지 않는다.

## 본문 구조

1. 청소했는데 먼지가 다시 남는 구체적인 장면과 감정
2. 교체 개월 수보다 현재 필터 상태가 우선이라는 핵심 판단
3. 먼지통·프리필터·배기필터의 역할과 관리 차이
4. 흡입력 저하·냄새·소음·표시등별 원인 구분
5. 세척으로 해결되는 상태와 교체가 필요한 상태 비교
6. 모델명과 공식 설명서로 물세척 가능 여부를 확인하는 방법
7. 필터를 덜 말렸을 때 생길 수 있는 문제와 안전한 건조 원칙
8. 필터가 아닌 흡입구·브러시·배터리 문제와의 구분
9. 독자가 바로 실행할 수 있는 5분 점검 순서
10. 정품·호환 부품을 단정하지 않고 모델별 교체 부품을 확인하는 방법
11. 다음 청소 전에 점검 순서를 저장하도록 마무리

## 사실 검증

- 발행 또는 수정 당일 국내 판매 제품의 공식 제조사 설명서·고객지원 문서를 실제로 연다.
- 물세척 가능 여부, 분리 방법, 건조 방법, 경고 사항은 모델마다 다르므로 일반화하지 않는다.
- 제조사 권장 교체 주기가 확인된 경우에만 제품명과 기준일을 내부 브리프에 기록한다.
- 특정 증상을 필터 문제로 단정하지 않고 흡입구 막힘, 브러시, 배터리 또는 서비스 점검 가능성을 구분한다.
- 확인할 수 없는 수치와 효과는 쓰지 않는다.

## 이미지 설계

- 대한민국에서 촬영되었거나 국내 제조사가 공식 제공한 실제 제품 사진을 우선한다.
- 사진의 게시·재사용 가능 범위를 확인하고 근거를 내부 브리프에 남긴다.
- 필요한 장면은 대표 이미지, 필터 종류, 오염·손상 판단, 설명서 확인, 점검 순서다.
- 모든 사진은 관련 문단 가까이에 배치하고 사진이 설명하는 판단을 캡션으로 작성한다.
- 사용권이 불명확한 검색 이미지와 방송·블로그 사진은 복제하지 않는다.
- 실사진 확보 실패 시 이유를 기록한다. 이 글에서는 장식 목적의 AI 사진으로 빈자리를 채우지 않는다.

## 네이버 편집 규칙

- 제목을 제외한 모든 본문 문단을 가운데 정렬한다.
- 완결된 의미 묶음 사이에 빈 문단 하나를 둔다.
- 소제목은 이모티콘 1개, 굵게, 밑줄, 핵심 색상 또는 연한 배경색으로 본문과 구분한다.
- 핵심 판단 인용구 2개, 실제 네이버 구분선 약 4개를 정보 전환 지점에 사용한다.
- 문자로 만든 구분선은 사용하지 않는다.
- 하단에 출처·사진 라이선스·연락처·태그 덤프를 넣지 않는다.
- 검색 태그는 네이버 태그 입력란에만 등록한다.

## 품질 게이트

다음 조건을 모두 충족해야 수정 예약 발행 단계로 이동한다.

- 제목의 약속을 본문에서 실제로 해결한다.
- 첫 다섯 문장에 구체적인 장면, 감정, 문제, 다음 문장을 읽게 할 질문이 있다.
- 필터 종류와 모델별 차이를 설명한다.
- 세척·건조·교체·전문 점검의 판단 기준이 서로 구분된다.
- 독자가 바로 실행할 수 있는 점검 순서와 하지 말아야 할 행동이 있다.
- 공식 근거와 이미지 권리가 내부 브리프에 기록되어 있다.
- 이미지마다 본문상 역할과 캡션이 있다.
- 회사소개와 상담 유도가 없다.
- `validate_brief.py`와 `validate_draft.py --engine traffic`을 통과한다.
- 실제 네이버 편집 화면과 모바일 미리보기에서 정렬, 여백, 강조, 인용구, 구분선, 사진, 캡션을 확인한다.

## 발행 방식과 실패 처리

기존 공개 글을 수정할 수 있으면 동일 URL을 유지하는 수정 발행을 우선한다. 이미 공개된 글을 별도 예약 글로 복제하지 않는다. 네이버가 공개 글의 예약 수정 발행을 지원하지 않거나 편집기에서 해당 기능을 확인할 수 없으면 즉시 수정 발행할지 새 글로 예약할지 사용자에게 보고하고 결정받는다.

로그인 만료, CAPTCHA, 편집기 변경, 정책 경고, 공식 근거 부족, 이미지 권리 불명확, 검증 실패 또는 공개 QA 실패가 발생하면 발행을 중단하고 원고·자산·재개 지점을 보존한다.

## 완료 조건

공개 페이지에서 제목, 전체 가운데 정렬, 의미 묶음 여백, 소제목 강조, 인용구, 실제 구분선, 사진과 캡션, 카테고리, 공개상태, 태그를 다시 확인한다. 독자가 글만으로 `청소·건조·교체·점검` 중 하나를 판단할 수 있어야 완료로 인정한다.
