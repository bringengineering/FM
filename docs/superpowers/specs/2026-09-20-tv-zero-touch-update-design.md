# TV 무인 자동 갱신 설계

## 목표

회사 TV 운영보드는 최초 승인 후 사람이 `Ctrl+F5`를 누르지 않아도 업무 데이터와 웹 프로그램을 계속 최신 상태로 유지한다.

## 동작

- 게시된 업무 데이터는 기존처럼 15초마다 확인한다.
- TV 웹 프로그램은 60초마다 `/tv/version`을 조회한다.
- 서버 버전이 현재 실행 버전과 달라지면 캐시를 우회한 주소로 페이지를 한 번 다시 연다.
- HTML, JavaScript, CSS는 재시작 시 반드시 최신 파일을 받도록 `no-store`로 제공한다.
- 일시적인 네트워크 오류는 현재 화면을 유지한 채 다음 주기에 다시 확인한다.
- 화면 순환, 기기 승인 쿠키, 마지막 정상 게시자료 보관 동작은 그대로 유지한다.

## 성공 기준

1. `/tv/version`은 현재 웹 프로그램 버전을 JSON으로 반환하고 캐시되지 않는다.
2. TV JavaScript는 60초마다 버전을 확인하고 버전 변경 시 캐시 우회 재시작을 수행한다.
3. 웹 자산은 `no-store`로 제공된다.
4. 기존 페어링, 15초 데이터 수신, 30초 화면 순환 테스트가 모두 통과한다.
5. 배포 후 실제 TV 주소에서 버전 응답과 자동 순환을 확인한다.

## 제외 범위

- Windows 시작 시 브라우저 자동 실행 설정은 이번 Worker 수정에 포함하지 않는다.
- 사용 중인 화면 중간에 즉시 강제 재시작하지 않고, 버전 확인 주기에만 재시작한다.
