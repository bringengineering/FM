# Drive 용역·정기청소 CRM 반영 설계

## 1. 목표

Google Drive에 보관된 완료보고서와 대표가 입력한 정기 서비스 조건을 CRM의 건물 운영 이력으로 연결한다. 원본 문서는 Drive에 유지하고, CRM에는 검색·일정·비용 관리에 필요한 구조화 정보와 원본 링크만 저장한다.

## 2. 확정된 첫 자료

- 건물: `북원로 2475번길 93`
- 예초 완료보고서: Drive 파일 `1cS3-f7JM4mrs6p321r7bftYrGF4qyIPK`
- 예초 작업일: `2026-08-15`
- 업체: `사계절제초작업`
- 업체 연락처: `010-5372-2319`
- 작업비: `150,000원`
- 작업 내용: 건물 외부 수목·벽면·통행로 주변 예초 및 정리
- 결과: 완료, 추가 조치 없음, 전후 사진·영상 존재
- 계단청소: `주 1회`, `월 60,000원`, `계약 예정`, `시작일 미정`

## 3. 구조

건물 체크리스트 후보와 운영 이력 후보를 분리한다.

- `crmCompany/driveImportCandidates/{driveFileId}`: 건물 등록 검토 후보
- `crmCompany/serviceImportCandidates/{driveFileId}`: 완료보고서 검토 후보
- `crmCompany/data/serviceRecords/{serviceRecordId}`: 승인된 단발성 용역 이력
- `crmCompany/data/serviceContracts/{serviceContractId}`: 정기 서비스 계약
- `crmCompany/data/serviceSchedules/{scheduleId}`: 계약에서 생성되는 실행 일정
- `crmCompany/driveImportAuditLogs/{auditId}`: 승인·반려·계약 생성 감사기록

Drive 파일 ID와 서비스 계약 ID를 멱등키로 사용한다. 예초 보고서를 다시 읽어도 완료 이력이 중복 생성되지 않고, 계단청소 일정은 같은 계약·같은 주차에 한 건만 존재한다.

## 4. 화면과 흐름

CRM의 건물 상세에 `운영 서비스` 섹션을 둔다.

1. Drive 완료보고서는 `검토 대기`로 표시한다.
2. 대표가 건물·업체·작업일·금액·결과를 확인해 승인한다.
3. 승인 후 `완료 이력`에 예초 작업이 나타나고 Drive 원본을 열 수 있다.
4. 계단청소는 `정기 계약` 카드로 표시한다.
5. 시작일 입력 전에는 `계약 예정 · 시작일 미정`으로 보이며 일정은 만들지 않는다.
6. 시작일이 입력되면 주 1회 일정을 만들고 완료·미완료·연기 상태를 기록한다.

admin만 Drive 후보 승인·반려 및 계약 생성·수정이 가능하다. member는 일정 완료 기록이 가능하고 viewer는 읽기만 가능하다.

## 5. 보안과 데이터 경계

- 원본 PDF·DOCX·사진·영상은 Drive에만 둔다.
- Firebase에는 원본 링크, 파일 ID, 금액, 일정, 업체, 결과 요약만 저장한다.
- Apps Script가 Drive 후보 생성과 승인 요청을 중계한다.
- 승인 시 Firebase ID token, UID, 이메일, 활성 CRM access, 역할을 다시 검증한다.
- 후보·감사로그는 클라이언트 직접 쓰기를 금지한다.
- 업체 연락처는 승인 후 서비스 이력에 저장하되 UI에서 일반 본문 로그로 출력하지 않는다.
- 출입 비밀번호나 민감한 현장 정보는 이 흐름에서 수집하지 않는다.

## 6. 오류 처리

- 건물 체크리스트가 아직 승인되지 않았거나 기존 CRM 건물과 연결되지 않으면 서비스 승인도 보류한다.
- Drive 원본이 없어지면 기존 이력은 삭제하지 않고 원본 상태만 `stale`로 표시한다.
- 원본 수정은 승인된 이력을 자동 덮어쓰지 않고 재검토 후보를 만든다.
- 동일 파일·동일 계약·동일 주차의 중복 저장을 거부한다.
- 시작일 미정 계약은 일정 생성 오류가 아니라 정상 대기 상태로 처리한다.

## 7. 완료 기준

- 예초 완료보고서가 1개의 검토 후보로 수집된다.
- 승인 전에는 정식 서비스 이력이 생성되지 않는다.
- 승인 후 북원로 2475번길 93 건물에 예초 완료·2026-08-15·150,000원·업체·원본 링크가 표시된다.
- 같은 Drive 파일을 재처리해도 완료 이력이 한 건만 유지된다.
- 계단청소 계약이 주 1회·월 60,000원·시작일 미정으로 표시된다.
- 시작일 미정에는 실행 일정이 0건이다.
- 시작일을 나중에 입력하면 해당 주부터 일정이 중복 없이 생성된다.
- 권한 없는 승인·수정은 거부된다.
