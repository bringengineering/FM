# BRING CARE 광고 랜딩 브랜드 선언 영역 설계

## 목표

기존 4개 광고 랜딩페이지의 디자인과 본문을 변경하지 않고, 각 페이지 최상단에 BRING CARE가 단순 청소업체가 아니라 건물관리와 청소를 함께 수행하는 회사임을 즉시 설명하는 공통 브랜드 선언 영역을 추가한다.

## 적용 페이지

- `/turnover-care`
- `/stair-cleaning`
- `/building-care`
- `/move-in-cleaning`

## 화면 구조

공통 브랜드 선언 영역은 각 페이지의 기존 첫 요소보다 앞에 렌더링한다. 기존 헤더, 히어로, 서비스 범위, 가격표, 견적 신청 폼은 순서와 내용 및 디자인을 유지한다.

영역은 승인된 정장 단체사진 `/brand-campaign/bringcare-suited-team-building-v3.png`을 크게 보여주고 다음 메시지를 함께 표시한다.

- 제목: `우리는 건물을 관리하며, 청소까지 책임지는 회사입니다.`
- 설명: `관리에는 현장을 직접 살피는 일이 포함되어 있으니까. 청소부터 시설 확인, 공실과 입·퇴실 관리까지 BRING CARE가 직접 살피고 기록합니다.`
- 기본 CTA: `서비스 알아보기` — 같은 페이지의 기존 첫 서비스 영역으로 이동
- 견적 CTA: `무료 견적 신청` — 같은 페이지의 기존 견적 폼으로 이동

## 시각 원칙

- 기존 랜딩의 파란색, 글꼴, 버튼 스타일을 재사용한다.
- 사진 위 텍스트 가독성을 위한 최소한의 오버레이만 사용한다.
- 새로운 카드, 가격, 기능 설명은 추가하지 않는다.
- 데스크톱에서는 사진과 메시지를 한 화면에서 인식할 수 있게 하고, 모바일에서는 텍스트와 CTA가 잘리지 않게 세로로 배치한다.
- 의미 있는 사진에는 구체적인 대체 텍스트를 제공한다.

## 변경 금지 범위

- 기존 페이지의 사진 교체 금지
- 기존 섹션 삭제·재배열 금지
- 기존 문구·가격·견적 폼 수정 금지
- 홈페이지 `/` 변경 금지

## 검증 기준

- 4개 페이지 모두 브랜드 선언 영역이 정확히 한 번 표시된다.
- 공통 제목과 승인된 단체사진이 모두 표시된다.
- 기존 페이지별 핵심 히어로 제목과 견적 폼이 그대로 남아 있다.
- PC와 모바일에서 가로 스크롤이나 CTA 겹침이 없다.
