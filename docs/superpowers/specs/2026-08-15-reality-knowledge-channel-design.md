# 현실지식 AI 쇼츠 채널 설계

## 목표

- 25~44세 남녀가 실제로 궁금해하고 생활의 판단에 활용할 수 있는 현실지식 영상을 만든다.
- 100일 안에 유튜브 구독자 100만 명을 도전 목표로 둔다. 달성을 보장하지 않으며 조회수, 구독 전환, 유지율을 선행지표로 관리한다.
- 콘텐츠 자체의 광고·협찬·제휴·확장 상품 수익을 만든다.
- 여러 분야를 실험해 대중의 관심사 데이터를 축적한다.
- 기존 건물관리 사업과 콘텐츠 소재 및 채널 운영을 연결하지 않는다.

## 콘텐츠 범위

돈, 소비, 직장, 관계, 심리, 기술, 건강, 사회현상, 기업의 수익구조와 생활상식을 폭넓게 다룬다. 모든 영상은 `평범한 상황 → 예상 밖 결과 → 숨은 구조 발견 → 중요한 예외 → 생활에 적용할 판단 기준`을 따른다.

## 소재 선정

후보는 검색 수요, 뉴스와 공개자료, 커뮤니티 질문, 유사 영상 반응에서 수집한다. 커뮤니티는 수요 탐색에만 사용하고 사실 근거로 사용하지 않는다.

각 후보에 두 점수를 부여한다.

- 미디어 성장 점수: 공감도, 궁금증, 훅, 완주 가능성, 공유 가능성, 시각화, 구독 전환
- 시청자 가치 점수: 정확성, 생활 적용성, 판단 개선, 피해 예방, 출처 품질

75점 미만이거나 핵심 주장의 원출처가 없는 후보는 제작하지 않는다.

## 역할 분리와 검증

1. 트렌드 수집자가 후보와 출처를 수집한다.
2. 수요 분석가와 반대 분석가가 각각 제작 찬성·반대 근거를 작성한다.
3. 편집장이 제작·보류·폐기를 결정한다.
4. 전문 리서처가 사실 문서를 만들고, 독립 반증 조사자가 제한 조건과 반례를 찾는다.
5. 팩트체커가 사실·해석·추정·사용 금지 표현으로 분류한다.
6. 스토리 작가가 대본을 작성하고, 이해도 편집자·공감 검사자·과장 검사자가 독립 검토한다.
7. 장면 연출자가 영상 프롬프트를 만들고, 시각 검증자가 장면과 주장의 일치를 확인한다.
8. 완성 영상은 자막·음성·숫자·출처·AI 시각 오류 검사를 거친다.
9. 초기 30일은 대표가 최종 승인한다. 고위험 분야는 이후에도 사람 승인을 유지한다.

## 자동 중단 조건

- 핵심 숫자나 인과관계의 원출처를 확인하지 못함
- 제목과 실제 결론이 다름
- 금융·법률·건강을 개인화된 조언처럼 단정함
- 저작권 또는 개인정보 위험이 있음
- 음성·자막·영상 사이에 숫자나 의미 불일치가 있음
- 검증자 간 충돌이 해소되지 않음

## 제작 및 데이터 흐름

`수집 → 점수화 → 선정 → 전문조사 → 반증 → 대본 → 검증 → 영상 → 품질검사 → 대표 승인 → 업로드 → 1시간·6시간·24시간·72시간·7일·30일 성과 수집 → 다음 가설`

각 영상에는 실험 ID, 주제 영역, 훅 유형, 감정, 생활 가치, 길이, 업로드 시간, 대본 버전을 기록한다. 조회수뿐 아니라 첫 3초 유지, 평균 시청시간, 완주, 반복재생, 공유, 댓글, 구독 전환을 분석한다.

## 외부 연결

Codex를 조사·검증·제작·분석·보고의 지휘센터로 사용한다. 실제 렌더링, 업로드와 성과 수집은 Higgsfield 또는 대체 영상 모델, 음성·편집 도구, YouTube API, 저장소, 예약 실행 환경의 권한 연결이 필요하다. 영상 모델은 교체 가능한 구조로 두고 Higgsfield를 기본값으로 삼는다.

## 첫 파일럿

- 주제: 카드 혜택을 받으려다 오히려 더 쓰게 되는 이유
- 선정 이유: 25~44세 공통 생활문제, 손실회피 훅, 높은 적용성, 시각적 돈 흐름, 연구 근거 확보 가능
- 목표: 한 편을 통해 전체 검증 흐름과 산출물 형식을 시험한다.
- 산출물: 소재 점수표, 사실 문서, 반증 기록, 60~90초 대본, 훅 3종, 장면별 프롬프트, 제목·설명·출처, 검수표
