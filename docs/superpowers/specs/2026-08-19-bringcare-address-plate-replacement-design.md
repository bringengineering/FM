# 브링케어 도로명주소판 교체 현장사례 설계

## 목표

노후·훼손된 도로명주소판을 새 주소판으로 교체한 실제 현장을 사진 5장으로 상세히 기록한다. 확인되지 않은 교체 사유·비용·시간·효과는 만들지 않고, 사진에서 확인되는 기존 상태·작업 과정·완료 상태와 브링케어의 관리 관점을 전달한다.

## 게시물 설정

- 요청 모드: 현장사진작성
- 배포 목표: 혼합
- 글 유형: 현장사례
- 주 역할: 증거
- 핵심 검색어: 원주 건물관리
- 보조 검색어: 도로명주소판 교체, 건물 외부 표식 관리, 원주 소형건물 관리
- 독자: 원주 원룸·다가구·소형 상가 건물주
- 주 CTA: 카카오채널 `BRING Care`

## 제목과 메시지

- 추천 제목: `원주 건물관리 현장, 낡은 도로명주소판을 새 주소판으로 교체했습니다`
- 핵심 판단: 건물 외부의 작은 표식도 상태를 확인하고 필요한 시점에 정리해야 하는 관리 항목이다.
- 금지 주장: 공실 감소, 비용 절감, 즉각적인 효과, 법적 의무, 작업시간 및 비용 보장

## 본문 구조

1. 낡거나 알아보기 어려워진 외부 표식을 발견하는 건물주의 실제 상황
2. 현장에서 확인한 기존 주소판 상태
3. 새 주소판의 위치를 맞추고 부착하는 과정
4. 교체 후 가독성과 외부 표식 상태 확인
5. 건물 외부 표식도 일상 관리 항목이라는 판단
6. 브링케어의 현장 확인·정리·완료 사진 기록 역할
7. 카카오채널 상담 CTA

본문은 제목을 제외하고 모두 가운데 정렬한다. 모바일 기준 1~3문장의 짧은 의미 묶음과 빈 문단을 사용한다. 실제 인용구와 실제 구분선 컴포넌트를 각 전환부에 배치한다. 소제목에는 문맥에 맞는 이모티콘을 제한적으로 사용한다.

## 강조 규칙

- 녹색 형광펜: 교체·정리 후 달라진 핵심 문구
- 베이지 형광펜: 건물 관리 판단 기준
- 노란색 형광펜: 독자가 확인할 주의·행동 문구
- 한 화면에 여러 강조색이 겹치지 않도록 핵심 구절만 강조한다.

## 사진 순서와 역할

1. Photo 4: 기존 노후 주소판 상태
2. Photo 1: 새 주소판 부착 작업 전경
3. Photo 2: 위치와 수평을 맞추는 작업 과정
4. Photo 3: 새 주소판과 브링케어 관리 표식 근접 기록
5. Photo 5: 교체 완료 후 건물 입구 전경

Photo 1과 Photo 2는 유사하지만 각각 작업 시작과 위치 조정 과정으로 캡션을 구분한다. 다섯 장 모두 관련 문단 가까이에 분산 배치하며, 같은 사진을 반복 삽입하지 않는다.

## 개인정보 및 현장 보호

공개용 복사본에서 다음 내용을 식별할 수 없도록 가린다.

- 상세 번지 숫자
- 도로명
- QR 코드
- 건물명
- 유리 반사에 나타난 전화번호·인물·상호 등 식별정보
- 화면 가장자리의 식별 가능한 인물

원본은 덮어쓰지 않는다. 사진의 작업 장면, 건물 외관, 주소판 형태, 브링케어 로고는 유지하며 가림 외의 장면을 생성하거나 바꾸지 않는다.

## 사실과 역할 경계

- 확인 가능: 기존 주소판 모습, 새 주소판을 부착하는 작업 장면, 교체 후 모습, 브링케어 표식
- 브링케어 역할로 표현 가능: 현장 상태 확인, 주소판 교체 과정 기록, 완료 상태 확인
- 확인되지 않음: 교체 요청 주체, 제작 주체, 비용, 작업시간, 훼손 원인, 법적 기준, 외부업체 참여 여부
- 확인되지 않은 항목은 본문에서 제외한다.

## 검수 및 발행

브리프와 15개 항목 발행 묶음을 작성하고 전용 검증 스크립트를 통과시킨다. 최종 원고·사진·가림 상태를 확인한 뒤 사용자에게 공개 발행 승인을 받는다. 승인 후 로그인된 네이버 블로그 `bringcare`에 전체공개·검색 허용으로 게시하고, 공개 페이지를 다시 열어 사진 5장·정렬·강조·인용구·구분선·태그·CTA와 공개 URL을 확인한다.
