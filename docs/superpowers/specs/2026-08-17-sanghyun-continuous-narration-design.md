# 상현 연속 나레이션 교체 설계

## 목표

펩시 전투기 쇼츠의 필재 음성을 상현 정속 음성으로 교체하고, 단어 단위 음성 절단으로 발생한 끊김을 완전히 제거한다.

## 확정 설정

- Typecast 성우: Sanghyun (`tc_69fc0cff784968297fb45daa`)
- 모델: `ssfm-v30`
- 언어: 한국어
- 속도: `1.00`
- 감정: `normal`, 기본 강도
- 음량: 최종 영상 기준 약 `-14 LUFS`, true peak `-1.5 dBTP` 이하

## 처리 구조

1. 전체 대본을 한 번의 Typecast 요청으로 합성한다.
2. 반환된 연속 WAV는 단어 또는 자막 단위로 자르지 않는다.
3. Typecast 단어 타임스탬프는 자막과 그림 시작 시각 계산에만 사용한다.
4. 원본 발화 안의 짧은 호흡은 유지한다.
5. 비정상적으로 긴 무음만 별도 검출하며, 음성 중간에 인공 무음을 삽입하지 않는다.
6. 기존 55개 그림은 각 나레이션 구절의 실제 시작 시각에 맞춰 전환한다.
7. 최종 합성 시 자막, 그림, 연속 음성이 동일한 Typecast 타임스탬프 원본을 공유한다.

## 오류 방지

- 음성 파일을 단어별 바이트 범위로 재조립하는 함수 사용 금지
- 성우 ID가 상현이 아니면 렌더링 중단
- 음성 속도가 1.00이 아니면 렌더링 중단
- 타임스탬프가 역순이거나 그림 앵커를 찾지 못하면 렌더링 중단
- 최종 영상에서 0.3초 이상 비정상 무음과 음량을 자동 검사

## 검증

- 전체 대본 연속 WAV와 최종 영상의 음성 구간 파형 비교
- 문장 중간의 인공적인 0.035초 무음이 존재하지 않는지 검사
- 시작, 계산, 주문, 소송, 판결, 결말 구간을 각각 청취·프레임 확인
- 기존 자막 안전영역과 파란 제목 스타일 유지
