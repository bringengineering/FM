# 브링케어 에어컨 배수·배관 문제 벽지 현장 BEFORE 글 설계

## 목표

오늘 확인한 실제 현장 사진 3장을 사용해 에어컨 배수·배관 문제로 벽지에 곰팡이와 박리가 생긴 작업 전 상태를 기록한다. 이번 글은 2부작 중 1편이며, 도배 완료 후 같은 위치를 다시 촬영해 2편에서 결과를 연결한다.

## 글의 역할

- 요청 모드: 현장사진작성
- 배포 목표: 혼합
- 콘텐츠 엔진: brand_field
- 게시물 유형: 현장사례
- 주역할: 증거
- 보조역할: 신뢰
- 핵심 독자: 원룸·다가구 또는 소형 건물을 관리하며 벽지 곰팡이·들뜸 문의를 받은 건물주
- 본문 주 CTA: 카카오채널

## 사실 범위

### 공개 가능한 확인 사실

- 2026년 8월 25일 브링케어가 현장을 방문해 상태를 확인했다.
- 에어컨 배수 또는 배관 문제가 원인으로 확인됐다.
- 그 영향으로 벽지에 곰팡이, 변색, 들뜸과 박리가 발생했다.
- 도배업체를 불러 작업을 진행하기로 했다.
- 첨부된 3장은 도배 작업 전 BEFORE 사진이다.
- 도배 완료 후 브링케어가 다시 방문해 같은 위치를 촬영할 예정이다.

### 공개하지 않거나 단정하지 않는 내용

- 상세 주소, 건물명, 호실, 임차인 정보
- 배수·배관 문제의 세부 부위와 수리 주체가 제공되지 않은 경우의 추정
- 도배 비용, 작업 기간, 자재 종류
- 아직 촬영되지 않은 작업 결과와 개선 효과
- 건강 영향, 곰팡이 종류, 구조체 손상 여부

## 역할 경계

- 브링케어: 문의 접수, 현장 확인, 상태 사진 기록, 문제 분류, 건물주 전달, 도배업체 일정 조율, 완료 후 재방문과 결과 사진 확인
- 외부 전문업체: 실제 도배 시공과 필요한 전문 작업
- 건물주: 비용과 작업 범위 승인

브링케어가 직접 도배 시공을 한 것처럼 표현하지 않는다.

1. 문을 열고 마주한 벽면의 구체적인 장면과 감정
2. 사진 1: 천장 모서리와 에어컨 주변까지 이어진 흔적
3. 벽지 교체보다 원인 확인이 먼저였다는 판단
4. 사진 2: 벽지 박리와 검은 변색이 넓게 이어진 상태
5. 에어컨 배수·배관 문제로 확인된 사실
6. 사진 3: 문 옆부터 벽면 전체가 보이는 작업 전 범위
7. 브링케어의 현장 확인·기록·업체 조율 역할
8. 도배 작업 예정과 2편 애프터 촬영 예고
9. 카카오채널 CTA 하나
10. 승인된 상담 배너를 글의 마지막에 한 번만 배치

## 네이버 편집 형식

- 제목을 제외한 모든 문단 가운데 정렬
- 의미 묶음 사이 빈 문단 하나
- 강조 소제목 4~6개에 굵게·밑줄·연한 배경색 적용
- 실제 인용구 1~2개
- 실제 구분선 3~4개
- 사진 3장을 관련 문단 가까이에 분산하고 각각 캡션 배치
- 자연스러운 이모티콘은 소제목과 전환 문장에만 제한적으로 사용
- 공개 본문 하단에 출처·사진 라이선스·연락처·태그 덤프를 넣지 않음
- 네이버 태그 입력란에만 검색 태그 등록
- 상담 배너는 모든 문장이 끝난 뒤 마지막에 정확히 한 번 배치

## 2편 연결 규칙

도배 완료 후 가능하면 1편과 같은 세 구도로 애프터 사진을 촬영한다. 2편에서는 시공 완료 상태만 기록하고, 제공되지 않은 비용·공법·효과는 만들지 않는다. 1편과 2편을 상호 연결하되 2편이 공개되기 전에는 1편에서 결과 링크를 만들지 않는다.

## 검증과 중단 조건

- 원인·작업 주체·사진 상태가 사용자 제공 사실과 일치하는지 검증한다.
- `validate_brief.py`와 `validate_draft.py`를 실행한다.
- 개인정보, 미확인 사실, 도배 결과 선행 주장, 브링케어 직접 시공 오인이 있으면 발행하지 않는다.
- 네이버 편집 화면에서 가운데 정렬, 문단 여백, 소제목 강조, 인용구, 구분선, 사진, 캡션, 카테고리, 태그, 상담 배너 마지막 1회를 확인한다.
- 최종 공개 버튼을 누르기 직전에 사용자에게 제목·공개 범위·카테고리를 보여주고 승인을 받는다.
