# CRM 신규 고객 자동 건물 연결 설계

## 목적

등록된 건물이 없어도 고객명만으로 신규 고객을 등록하고, 고객명과 동일한 새 건물 관리 항목을 자동 생성해 즉시 연결한다.

## 동작

- 신규 고객 등록에서 고객명은 필수, 기존 건물 선택은 선택사항이다.
- 기존 건물을 선택하면 새 건물을 만들지 않고 해당 건물과 고객을 연결한다.
- 기존 건물을 선택하지 않으면 고객명으로 새 건물을 생성하고 고객과 연결한다.
- 자동 생성 건물은 유형 `기타`, 상태 `영업후보`, 담당자는 고객 담당자와 동일하게 저장한다.
- 동일한 이름의 기존 건물이 있어도 이름만으로 자동 병합하지 않는다. 기존 건물 연결은 사용자가 선택한 경우에만 수행한다.
- 기존 고객 수정 시 건물을 선택하지 않아도 기존 연결을 유지하며, 자동 건물을 새로 만들지 않는다.
- 고객명과 건물 선택이 모두 없으면 등록을 차단한다. 이번 흐름에서는 고객명이 필수이므로 빈 고객명은 항상 차단한다.

## 데이터와 오류 처리

- 고객과 자동 생성 건물은 한 번의 로컬 상태 변경에서 함께 추가한 뒤 기존 공용 저장 경로를 사용한다.
- 건물 ID는 기존 ID 생성 규칙을 사용한다.
- 저장 실패 시 기존 동기화 오류 처리와 재시도 흐름을 유지한다.

## 검증

- 건물이 하나도 없는 상태에서 고객명만으로 고객과 건물이 각각 1건 생성되고 서로 연결되는지 검사한다.
- 기존 건물을 선택하면 새 건물이 생성되지 않는지 검사한다.
- 기존 고객 수정이 불필요한 자동 건물을 만들지 않는지 검사한다.
- 전체 CRM 테스트와 Windows 빌드를 실행한다.
