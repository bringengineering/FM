# BRING CARE 건물관리 경험 카드 설계

## 목적

실제 고객 후기 원문이 아직 사이트 자산으로 확보되지 않은 상태에서 가상 후기나 평점을 공개하지 않는다. 대신 실제 관리 현장 사진과 BRING CARE가 제공하는 검증 가능한 관리 효익을 후기 카드와 유사한 시각 형식으로 보여준다.

## 공개 섹션

- 영문 라벨: `MANAGEMENT EXPERIENCE`
- 제목: `건물주가 체감하는 관리의 차이`
- 설명: `직접 다녀오지 않아도 현장 확인부터 후속 조치까지 한눈에 파악할 수 있습니다.`
- 카드 수: 3개
- 카드 구성: 실제 현장 사진, 관리 경험 분류, 효익 제목, 설명, 업무 태그

### 카드 1

- 분류: 원거리 관리
- 제목: 멀리 있어도 확인이 쉬워집니다.
- 설명: 방문 결과를 현장 사진과 확인 항목으로 정리해 건물주가 직접 이동하지 않아도 상태를 파악할 수 있습니다.
- 태그: 공실 확인, 현장 기록

### 카드 2

- 분류: 통합 관리
- 제목: 연락할 곳을 줄여드립니다.
- 설명: 공실·공용부·시설 문제를 한 곳에서 접수하고 필요한 업체 연결과 결과 확인을 정리합니다.
- 태그: 입퇴실 관리, 공용부 확인

### 카드 3

- 분류: 완료 기록
- 제목: 확인에서 완료 기록까지 이어집니다.
- 설명: 발견한 문제와 진행한 조치, 남은 확인 사항을 한 흐름으로 정리해 전달합니다.
- 태그: 시설 확인, 업체 연결

## 표시 원칙

- `고객 후기`, `실제 고객 발언`, 고객명, 별점, 평점은 사용하지 않는다.
- 인용부호를 사용하지 않는다.
- `디자인 시안용 예시` 배너는 공개 페이지에서 사용하지 않는다.
- 실제 후기 원문이 확보되면 기존 `BuildingCareTestimonials`에 별도로 추가한다.

## 배치

`실제 관리 사례` 다음, 검증 후기 컴포넌트 이전에 배치한다. 검증 후기 데이터가 비어 있으면 관리 경험 카드만 보인다.

## 검증 기준

1. 관리 경험 카드 3개가 표시된다.
2. 실제 현장 사진 3장이 표시된다.
3. `시안용`, `실제 고객`, `4.9점`이 표시되지 않는다.
4. 검증 후기 데이터가 비어 있을 때 기존 후기 컴포넌트는 계속 렌더링되지 않는다.
5. 모바일과 데스크톱에서 가로 넘침이 없다.
