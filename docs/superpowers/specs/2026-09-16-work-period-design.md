# 프로젝트 업무 기간 통합 설계

## 승인된 후속 개발의 첫 범위
기존 프로젝트 화면에서 이번 주·지난주·전체 업무를 구분한다. 기존 결과보고·대표 검수·Word/PPT 기능을 재구현하지 않는다. 기존 CRM 카드와 버튼 스타일을 사용하고 서버 데이터는 수정하지 않는다.

## 현재 확인
- 업무 목록은 프로젝트와 내 것만/전체 범위를 지원하지만 주간 필터가 없다.
- 성과 현황은 별도의 전체/이번 주 집계 기간을 사용한다.
- 결과보고 입력, 서버 저장 확인, 문서 출력 모듈과 관련 테스트가 존재한다. 구현 존재와 실제 운영 흐름 검증 완료는 구분한다.

## 선택한 방법
단일 기간 필터를 목록과 성과에 공통 적용한다. 대안인 성과 전용 필터 유지 방식은 서로 다른 수치를 보여줄 수 있으며, 새 주간 전용 페이지는 탐색 동선을 늘린다.

## 동작
- 기본 기간은 이번 주. 이번 주·지난주·전체 버튼과 실제 시작/종료 날짜를 표시한다.
- 주간 범위는 PC 현지 달력 기준 월요일부터 일요일까지다. 날짜 전용 문자열을 UTC 변환으로 이동시키지 않는다.
- 업무 시작일~마감일과 선택한 주가 하루 이상 겹치면 포함한다. 한쪽 날짜만 있으면 그 날짜를 기준으로 한다.
- 날짜가 없거나 잘못된 업무는 주간 집계에서 제외하고 일정 확인 필요 건수 및 전체 보기 진입을 제공한다. 원본 기록은 삭제하지 않는다.
- 프로젝트/담당 범위/기간을 동일한 순서로 적용한다. 목록과 성과 집계의 조회 권한 차이는 안내하며 권한을 확대하지 않는다.
- 편집 중 필터 전환은 막아 미저장 입력을 보존한다.
- 지난주 미완료를 자동 이월하거나 마감일·상태를 바꾸지 않는다.
- 문서 출력에 별도 날짜 선택이 있다면 해당 선택을 유지하고 화면 기간과 혼동되지 않게 안내한다.

## 검증
주 경계·월/연 경계·일정 겹침·날짜 누락/역전·프로젝트/담당 결합·편집 중 전환 방지·기존 결과보고 회귀 테스트를 확인한다. 이번 변경은 서버 쓰기를 수행하지 않는다. 운영 배포 여부와 로컬 검증 결과는 별도로 보고한다.
