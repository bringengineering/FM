# Veo 마트 과소비 쇼츠 재제작 설계

## 목표

기존 정지 슬라이드 초안을 폐기하고, 사용자가 합격시킨 움직이는 졸라맨 영상의 수준으로 `우유 하나 사러 갔다가 138,240원을 쓴 이유`를 110~120초 세로 쇼츠로 재제작한다.

## 합격 기준

- 영상은 9:16, 1080×1920, 30fps 최종 출력이다.
- 생성 원본은 Veo 3.1 Lite 720p, 장면당 8초를 사용한다.
- 총 15개 장면, 생성 예산 상한은 120크레딧이다.
- 정지 이미지에 줌만 넣은 장면은 허용하지 않는다.
- 모든 장면에는 인물·소품·배경 또는 카메라의 명확한 움직임이 있어야 한다.
- 수진의 머리 모양, 노란 몸통선, 얼굴선, 신체 비율은 장면 전체에서 동일해야 한다.
- 표정은 장면 감정에 맞춰 바뀔 수 있지만 눈과 입이 사라지는 프레임은 허용하지 않는다.
- 생성 영상 안에는 한글·영문·일문·중문·가격표·로고·워터마크를 넣지 않는다.
- 대사는 Typecast `필재`, 자막은 한 번에 한 줄만 표시한다.
- 대사 사이 침묵은 원칙적으로 0.25초 이하로 유지한다.

## 제작 구조

1. 고정 캐릭터 원본과 장면별 환경을 합성한 시작 프레임 15개를 만든다.
2. 각 시작 프레임을 Veo 3.1 Lite에 넣어 8초 영상으로 변환한다.
3. 프롬프트에는 한 장면당 하나의 핵심 행동과 하나의 카메라 동작만 지정한다.
4. 15개 영상을 순서대로 편집하고 장면 경계의 불필요한 정지 구간을 제거한다.
5. Typecast 음성, 발화 동기화 한 줄 자막, 효과음을 후편집한다.
6. 최종 길이를 110~120초로 맞추고 기술 검수 후 게시 후보로 전달한다.

## 1번 장면 시험 생성

- 배경: 퇴근 시간의 회사 로비와 회전문, 집이 아닌 환경.
- 행동: 축 처진 수진이 회전문을 빠져나오며 휴대전화를 확인한다.
- 카메라: 건물 외부 전경에서 수진에게 부드럽게 접근한다.
- 스타일: 얇은 검은 선, 따뜻한 흰 배경, 절제된 파스텔, 귀여운 2D 편집 만화.
- 금지: 사실적 인물, 3D 캐릭터, 생성 문자, 캐릭터 변형, 얼굴 요소 소실.

1번 장면에 8크레딧만 사용해 시험 생성한다. 캐릭터 일관성, 실제 움직임, 배경 밀도, AI 왜곡을 검수해 합격한 경우에만 나머지 14개를 생성한다.

## 비용 통제

- 시험: 8크레딧
- 합격 후 잔여 14개: 112크레딧
- 총 상한: 120크레딧
- 실패한 시험 장면은 자동 재생성하지 않으며, 추가 크레딧 사용 전에 원인을 수정하고 승인을 받는다.

## 검수

- 캐릭터: 장면 시작·중간·종료 프레임 비교
- 문자: OCR 및 육안으로 생성문자 확인
- 음성: 대사 누락·잘림·긴 침묵 확인
- 자막: 한 줄 여부와 발화 싱크 확인
- 출력: 길이, 해상도, 프레임률, 디코딩, 음량 확인
