# 브링이슈 공용 쫄라맨 리액션 라이브러리 설계

## 목표

하루 5편의 쇼츠를 만들 수 있도록 영상마다 모든 그림을 새로 생성하지 않는다. 영상 한 편은 사건별 신규 핵심 그림 12장과 공용 쫄라맨 리액션 자산을 결합한다. 2분 영상의 화면 변화는 50~60회로 유지하되, 동일 원본 이미지의 무의미한 반복은 방지한다.

## 고정 캐릭터

- 흰색 원형 얼굴
- 검은색 얇은 팔다리와 굵고 깨끗한 외곽선
- 머리 위 검은 잔머리 세 가닥
- 기본 복장은 흰 티셔츠, 붉은 체크 셔츠, 청바지, 흰 운동화
- 얼굴과 체형의 비율은 모든 자산에서 동일
- 따뜻한 종이 질감의 한국식 편집 만화 스타일
- 배경은 투명 또는 단색으로 제작하여 어느 시대·장소에도 합성 가능
- 이미지 내부에는 자막, 브랜드 로고, 워터마크, 의미 없는 문자를 넣지 않음

## 제작 형식

- 마스터 캐릭터 시트 5장, 장당 6개 포즈
- 각 포즈는 독립 PNG로 자동 분리
- 세로 영상 합성을 고려해 캐릭터 주변 여백 확보
- 출력 원본은 최소 1536px 이상의 정사각형 또는 세로 캔버스
- 최종 개별 자산은 투명 배경 PNG
- 파일명: `reaction_01_default.png`부터 `reaction_30_exit.png`
- 각 자산에 감정, 행동, 권장 대사 유형, 좌우 배치 가능 여부를 기록한 JSON 매니페스트 제공

## 영상별 사용 규칙

- 한 편에서 공용 리액션은 8~15회 사용
- 같은 리액션을 한 편에서 최대 2회만 사용
- 같은 원본의 연속 노출 금지
- 공용 리액션 사이에는 신규 핵심 그림, 실제 자료 또는 설명 카드를 배치
- 화면 변화 간격은 평균 1.5~2.5초, 단일 화면은 최대 3초
- 공용 리액션에는 미세 줌, 좌우 이동, 배경 교체를 허용하지만 이를 새로운 원본 그림으로 집계하지 않음

## 편당 표준 구성

- 사건별 신규 핵심 그림: 12장
- 공용 리액션 사용: 8~15컷
- 실제 자료·시대 배경: 8~12컷
- 숫자·관계도·타임라인 카드: 5~8컷
- 총 화면 변화: 50~60회

## 품질 검수

- 30개 자산의 얼굴 비율, 머리카락, 체크 셔츠, 바지 색상 일치
- 손가락·팔다리 누락 또는 비정상 변형 없음
- 이미지 내부의 글자·로고·워터마크 없음
- 배경 제거 후 외곽선 손상 없음
- 9:16 화면의 좌·중·우 배치에서 잘리지 않음
- 30개 자산의 perceptual hash를 비교하여 사실상 동일한 포즈가 중복되지 않음

## 현재 펩시 영상 적용

이미 생성된 28장 가운데 스토리 핵심 12장을 선정한다. 나머지는 공용 리액션으로 억지 전환하지 않고, 이번 라이브러리의 리액션과 실제 사건 자료·도표를 조합해 약 55회의 화면 변화로 편집한다.
