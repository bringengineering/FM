# 브링케어 네이버 블로그 전면 개편 설계

## 1. 목적과 결론

브링케어 블로그를 활동 기록 모음에서 `원주 원룸·다가구 입·퇴실 관리`의 검색 유입과 상담 전환을 담당하는 공식 영업 채널로 전환한다.

대표 포지셔닝은 다음과 같다.

> 원주 원룸·다가구 입·퇴실 관리<br>
> 퇴실 14일 전부터 준비해, 중대한 수리가 없는 호실은 퇴실 후 24시간 안에 다음 임대 준비 상태로 전환합니다.

브링케어는 새 임차인의 계약 시점을 보장하지 않는다. 차별성은 임차 수요가 아니라 브링케어가 통제할 수 있는 `퇴실 통보 접수부터 다음 임대 준비 완료까지의 운영 시간`을 줄이는 데 둔다.

기존 로고와 블루 계열을 유지한다. 디자인은 전문회사형 서비스 포털을 기본으로 하고, 24시간 후킹과 실제 현장 증거를 결합한다.

## 2. 핵심 고객

최우선 고객은 원주 밖에 거주하거나 여러 건물을 운영해 퇴실 때마다 직접 방문하기 어려운 원룸·다가구 건물주다.

이 고객의 핵심 문제는 다음과 같다.

- 퇴실 통보 이후 청소·보수·중개 준비가 각각 따로 움직인다.
- 현장 확인이 늦어져 필요한 작업이 퇴실 당일에야 드러난다.
- 청소와 보수 사이에 대기 시간이 생긴다.
- 업체마다 별도로 연락하고 결과를 다시 확인해야 한다.
- 다음 임대 준비가 언제 끝나는지 한눈에 알기 어렵다.

## 3. 대표 상품

### 공개 상품명

`브링케어 24H 입·퇴실 관리 패키지`

### 캠페인 문구

`공실 0일을 목표로, 퇴실 14일 전부터 움직입니다.`

`공실 0일`은 상품명이나 목표 표현으로만 사용한다. 조건 없는 결과 보장이나 24시간 안의 신규 임차계약 보장으로 표현하지 않는다.

### 브링케어가 약속하는 범위

적용 조건을 모두 충족하고 중대한 수리가 없는 호실은 퇴실 완료 후 24시간 안에 다음 임대에 필요한 청소·경미한 정리·사진 기록·인계 준비를 완료하는 것을 운영 기준으로 삼는다.

### 적용 조건

- 퇴실 예정일 기준 14일 전까지 접수
- 건물주 또는 적법한 관리 권한자의 요청
- 기존 임차인과 출입·촬영·점검 일정 협의 완료
- 열쇠 또는 출입 권한 확보
- 수도와 전기 사용 가능
- 건물주의 작업 범위와 비용 승인 완료
- 폐기물, 심한 오염, 누수, 전기, 구조, 대규모 도배·장판 등 중대한 추가 작업이 없음

### 제외·지연 조건

- 임차인 일정 변경 또는 출입 불가
- 대형폐기물·유품·과다 잔존물 처리
- 누수·곰팡이 원인 보수, 전기·가스·구조 문제
- 대규모 도배·장판·욕실·주방 공사
- 전문업체 자재 수급 또는 작업 일정 지연
- 건물주 승인 지연

제외 조건이 발견되면 24시간 완료를 주장하지 않고, 발견 시각·필요 작업·예상 다음 단계·건물주 승인 필요사항을 사진과 함께 보고한다.

## 4. 입·퇴실 운영 타임라인

### D-14: 접수

- 퇴실 예정일, 호실, 평형, 현재 임대 조건 접수
- 임차인·건물주·중개사 연락 창구 확인
- 출입과 촬영 동의 범위 확인

### D-10~D-7: 사전 준비

- 기존 기록과 확인 가능한 현장 정보 검토
- 청소팀 일정 선점
- 예상 보수 항목과 전문업체 대기 슬롯 확인
- 중개 준비에 필요한 기본 정보 정리

### D-3: 일정 확정

- 퇴실 확인 시간 확정
- 열쇠 인계 방식 확인
- 청소 투입 시간 확정
- 건물주 승인 범위 재확인

### D0: 퇴실 당일

- 퇴실 상태와 잔존물 확인
- 사진 기록
- 청소·경미한 개선 즉시 시작
- 추가 전문 작업이 필요한 항목 분류·보고

### D+1: 임대 준비 완료

- 청소 및 승인된 경미한 개선 완료 확인
- 같은 위치의 완료 사진 촬영
- 미완료·추가 확인 항목 구분
- 건물주와 중개 창구에 임대 준비 상태 전달

## 5. 수익 구조와 공개 가격 원칙

블로그는 저마진 진입상품과 고마진 후속사업의 관계를 내부적으로 이해하되, 고객에게 손해 감수나 마진 전략을 설명하지 않는다.

### 제안 공개안

- 월 정기 관리: 8만 9천 원부터, 부가세 별도
- 관리 계약 건물의 기본 입·퇴실청소: 10만 원부터, 부가세 별도
- 일반 단건 입·퇴실청소: 12만 원부터, 부가세 별도
- 외부 전문작업 연결·조율: 승인된 작업금액의 5%, 부가세 별도
- 현장 작업비·전문업체 시공비·자재비·폐기물비: 별도

가격은 평형, 오염도, 층수, 엘리베이터, 잔존물, 작업 범위에 따라 달라질 수 있음을 가격표 바로 아래 표시한다. 실제 공개 전 제안서와 회계 기준에서 부가세 포함 여부와 적용 대상을 최종 대조한다.

공간 기획·인테리어·시공은 입·퇴실 패키지에 포함하지 않는다. 별도 상담이 필요한 후속 서비스로만 표시한다.

## 7. 홈 디자인

### 상단 커버

- 기존 BR 심볼과 블루 계열 유지
- 왼쪽 55%는 문구 안전영역
- 오른쪽 45%는 한국의 3~5층 원룸·다가구와 관리자의 점검 장면
- 얼굴, 상세 주소, 호실, 차량번호 노출 금지
- 핵심 문구는 `퇴실 14일 전부터 준비합니다`
- 가장 큰 강조는 `24시간 임대 준비`
- 하단 키워드는 `퇴실확인 · 직영청소 · 보수연결 · 완료보고`

`공실 0일`은 커버의 가장 큰 문구로 사용하지 않는다. 과장 오인을 줄이기 위해 상품 공지와 캠페인 카드에서 `목표` 표현과 함께 사용한다.

- 작은 화면에서 읽히지 않는 부가문구 제거

### 색상

1. 검색: `원주 퇴실청소`, `원주 입퇴실관리`, `원주 공실관리`로 유입
2. 이해: 대표 이미지와 도입에서 24시간 임대 준비의 의미 확인
3. 검토: 적용 조건, 가격, 역할 경계 확인
4. 신뢰: 실제 BEFORE/AFTER와 사진 보고 과정 확인
5. 행동: 카카오채널로 퇴실 예정일·건물 위치·호실 평형 전송
6. 상담: 적용 가능 여부와 제외조건 확인
7. 계약: 범위·가격·일정 승인
8. 실행: D-14부터 일정과 기록 관리
9. 회고: 완료 시간, 추가 작업, 상담·계약 전환 기록

## 12. 콘텐츠 포트폴리오

브링케어 블로그는 사업과 직접 이어지는 콘텐츠에 집중한다.

- 40% 입·퇴실 검색정보
- 30% 실제 현장 BEFORE/AFTER
- 15% 가격·절차·FAQ
- 10% 건물주 의사결정 가이드
- 5% 회사 신뢰·운영 원칙

대중 트렌드와 제휴 중심 콘텐츠는 브링이슈에서 운영한다. 브링케어에 남아 있는 무관한 트렌드 글은 즉시 삭제하지 않고 검색 성과·권리·브랜드 혼선을 확인해 `유지`, `브링이슈 재제작`, `비공개 검토`로 분류한다.

## 13. 기존 글 정리 기준

### 유지·강화

- 실제 현장사진이 있음
- 브링케어의 역할이 확인됨
- 입퇴실·공실·청소·보수 검색 질문과 이어짐
- 개인정보와 역할 경계가 처리됨

### 수정

- 회사소개가 반복됨
- 가격·절차 공지로 연결되지 않음
- 제목과 도입의 검색 질문이 불분명함
- 실제 구분선·인용구·캡션이 부족함

### 비공개 검토

- 브링케어 사업과 무관한 순수 트렌드
- 저작권·출처·개인정보 문제가 있음
- 사실 확인이 불가능함
- 조회와 상담 기여가 모두 없고 브랜드 혼선을 만듦

삭제는 별도 승인 없이는 실행하지 않는다.

- 고객 현장
- BEFORE/AFTER
- 청소·점검·완료 사진
- 실제 작업과 결과 증명

AI 결과를 실제 관리 현장, 고객 사례, 전후 결과로 표현하지 않는다. 네이버의 AI 활용 표시가 필요한 게시물은 표시를 켠다.

Flow에서는 배경만 생성하고 BR 로고, `24H`, 한글 문구와 가격은 후편집으로 합성한다.

## 15. 공지와 본문 디자인 규칙

- 사진은 관련 문단 가까이에 배치하고 짧은 캡션을 입력

## 18. 안전·승인 게이트

- 블로그 설정 변경과 공개 글 수정은 실행 직전 사용자 승인
- 게시물 삭제·비공개 전환은 글 목록과 이유를 보여준 뒤 별도 승인
- 가격·부가세·적용대상은 공개 전 최종 대조
- `공실 0일`, `24시간`은 적용 조건과 측정 구간 없이 단독 사용 금지
- 개인정보·임차인 동의·촬영 권한 확인
- 전문 시공을 브링케어 직접 작업으로 오인시키지 않음
- Google Flow 이미지는 현장 증거로 사용하지 않음
