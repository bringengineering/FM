# 브링케어 현장 글 8개 전면 재편집 설계

## 목표

현재 공개된 현장 글 8개를 `브링케어_네이버블로그_마스터매뉴얼_v1.1.docx` 기준으로 다시 편집한다. 확인된 현장 사실과 개인정보 가림 사진은 유지하면서 모바일 가독성, 강조, 사진 배치, CTA와 공개 설정을 통일한다.

## 적용 범위

- 조경·넝쿨 정리
- 임대차 관리 세대 현장점검
- 화재예방 패드 설치
- 청소 중 하자 발견
- 건물 앞 쓰레기 정리
- 디지털 사이니지 설치
- 출입구 안내물 정비
- 호수판·벨 커버 교체

## 편집 규칙

1. 제목은 좌측 기본값을 유지하고, 제목을 제외한 본문 전체를 가운데 정렬한다.
2. 회사 인사보다 독자가 겪는 실제 상황으로 시작한다.
3. 한 문장 또는 한 의미 묶음이 끝날 때 빈 문단을 넣어 모바일 화면에 여백을 만든다.
4. 글마다 핵심 구절 2~3개만 글자 배경색으로 강조한다.
   - 연두: 변화·해결 포인트
   - 베이지: 판단 기준
   - 노랑: 주의·핵심 행동
5. 같은 화면에서 여러 강조색을 섞지 않고, 굵게·밑줄·배경색을 과도하게 중첩하지 않는다.
6. 핵심 판단 한 문장을 네이버 인용구 컴포넌트로 표현한다.
7. 도입에서 해결, 정보에서 서비스 연결로 넘어갈 때 네이버 실제 구분선 컴포넌트를 사용한다.
8. 이모티콘은 소제목 또는 감정 전환에 한 개씩만 사용하며 같은 이모티콘을 반복하지 않는다.
9. 사진은 본문 끝에 몰지 않고 도입·상태·판단·결과 문단 가까이에 나누어 배치한다.
10. 각 사진에 보이는 사실만 설명하는 짧은 캡션을 넣는다.
11. 개인정보가 있는 사진은 기존 가림 사본을 사용한다.
12. 쓰레기 정리 글의 재구성 이미지는 AI 활용 사실과 실제 완료 촬영본이 아니라는 점을 이미지 가까이에 밝힌다.
13. 본문에는 해시태그 묶음을 두지 않고 네이버 태그 입력란에 등록한다.
14. 브링케어 역할과 외부 전문업체 역할을 구분한다.
15. 한 글의 주 CTA는 하나로 제한한다.

## 글별 구조

각 글은 다음 흐름을 기본으로 한다.

1. 독자가 공감할 실제 장면
2. 이번 현장의 공개 가능한 배경
3. 사진에서 확인한 상태
4. 위험·생활 영향·시급성에 따른 판단
5. 브링케어의 확인·보고·조율 역할
6. 외부 작업 또는 완료 상태
7. 다음 관리 기준
8. 하나의 상담 CTA

## 검증

- 제목과 본문의 약속 일치
- 실제 사진과 AI 이미지 구분
- 상세 주소·호실·전화번호·차량번호 등 개인정보 비노출
- 제목 제외 본문 전체 가운데 정렬
- 사진 순서와 캡션 확인
- 형광펜이 핵심 구절에만 적용됐는지 확인
- 실제 인용구·구분선 컴포넌트 사용 확인
- 전체공개·검색 허용·카테고리·태그 확인
- 수정된 공개 URL을 다시 열어 모바일 호흡과 누락을 확인

## 완료 조건

8개 공개 글이 모두 위 규칙으로 수정 저장되고, 기존 공개 URL에서 수정된 제목·본문·사진·서식이 정상적으로 표시되는 것을 확인하면 완료한다.
