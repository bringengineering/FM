# BRING TV 로드맵 참고 시안 일치 설계

## 목표

실제 TV와 CRM 미리보기의 `프로젝트 로드맵` 장면을 사용자가 승인한 참고 시안과 같은 정보 계층으로 표시한다.

## 한 화면 구성

1. BRING 브랜드, 서버 연결 상태, 현재 시각
2. `프로젝트 로드맵` 제목과 조회 기간
3. 담당자 행과 8주 눈금, 오늘선, 프로젝트 기간 막대, 막대 내부 진행률
4. 정상 진행·기한 위험 범례
5. 하단 성과 카드 3개
   - 전체 프로젝트 진행률: 원형 진행률, 프로젝트 수, 전주 대비 문구
   - 프로젝트 상태: 정상·확인·위험·완료 수
   - 다가오는 마감: D-day, 프로젝트명, 담당자

## 동작

- 로드맵은 첫 장면이며 40초 노출한다.
- 담당자가 3명을 넘으면 다음 로드맵 페이지로 자동 전환한다.
- 다른 성과·일정 장면도 기존 순서대로 자동 순환한다.
- 1920×1080과 1366×768에서 한 화면 안에 들어오며 가로 스크롤이 없어야 한다.
- 프로젝트가 없을 때에도 로드맵 틀과 세 성과 카드는 유지한다.

## 디자인

- 기존 BRING CRM의 흰색 카드, 옅은 회색 배경, 파란색 강조색을 유지한다.
- 표와 눈금선은 약하게, 숫자와 진행률은 크게 표시한다.
- 상태는 색상과 글자를 함께 사용한다.
- TV에서는 설명용 제목·샘플 모음·긴 안내문을 표시하지 않는다.

## 데이터·보안

- 기존 공개 전용 로드맵·성과 모델만 사용한다.
- 고객명, 연락처, 주소, 상담 내용, 업무 원문은 추가하지 않는다.
- 게시되지 않은 프로젝트 데이터는 임의로 만들어 표시하지 않는다.

## 완료 기준

- 실제 TV와 CRM 미리보기에서 동일한 로드맵 정보 구조가 보인다.
- 하단에 성과 카드 3개가 나란히 표시된다.
- 자동 순환·자동 갱신·구형 데이터 호환이 유지된다.
- 전체 CRM, Worker, 회사 사이트 통합검사가 통과한다.
