# BRING TV 통합 설치 패키지 설계

## 목적

TV 컴퓨터 사용자가 메일에서 파일 하나만 내려받아 설치할 수 있도록 설치 프로그램, 사용 안내, 오류 진단 프롬프트를 하나의 ZIP 파일로 배포한다.

## 배포 파일

- 파일명: `BRING-TV-통합설치-v1.0.3.zip`
- 공개 위치: `bringengineering/FM` GitHub Release의 신규 태그
- 기존 v1.0.2 태그와 파일은 변경하거나 재사용하지 않는다.

## ZIP 구성

1. `BRING-TV-설치.cmd`
   - 사용자가 더블클릭하는 기본 설치 진입점
2. `install-bring-tv-web-kiosk.ps1`
   - Edge 우선, Chrome 대체 실행
   - 설치 직후 TV 운영보드 실행
   - Windows 로그인 시 자동 실행 등록
3. `BRING-TV-삭제.cmd` 및 삭제 스크립트
   - 자동 실행 설정을 제거하는 복구 수단
4. `사용방법.txt`
   - 압축 해제부터 설치 완료 확인까지 비기술 사용자용 안내
5. `BRING-TV-설치복구-프롬프트.txt`
   - 설치 실패 시 담당자 또는 AI에게 그대로 전달하는 진단 요청문
   - 바탕화면의 `BRING-TV-설치-오류.txt`를 함께 전달하도록 안내
   - 비밀번호, 인증코드, 쿠키를 입력하거나 공유하지 말라는 보안 문구 포함
6. `README.md`
   - 버전, 공개 URL, 설치 동작, 제거 방법, 무결성 정보

## 이메일 구성

- 수신: 기존 회사 Gmail 계정에서 본인에게 재발송
- 제목에 `v1.0.3 통합설치판`을 명시해 이전 메일과 구분
- 본문에는 신규 GitHub Release 직접 다운로드 링크를 하나만 제공
- 설치 순서와 실패 시 오류 파일 전달 방법을 짧게 기재
- 프롬프트 전문도 메일 본문 하단에 함께 넣어 ZIP을 열지 못해도 복사할 수 있게 한다.

## 오류 처리

- 설치 스크립트 오류는 바탕화면 `BRING-TV-설치-오류.txt`에 저장한다.
- Edge와 Chrome이 모두 없으면 설치가 중단되고 브라우저 설치 필요 사유를 기록한다.
- 시작프로그램 폴더 접근 실패 시 가능한 경로를 순서대로 시도하고 최종 실패 내용을 기록한다.
- 기존 등록 정보와 TV 페어링 값은 삭제하거나 초기화하지 않는다.

## 검증 기준

- PowerShell 구문 검사 통과
- TV 설치 스크립트 집중 테스트 통과
- ZIP 내부 필수 파일 6종 이상 존재 확인
- GitHub Release의 비로그인 다운로드 확인
- 로컬 파일과 공개 다운로드 파일의 SHA-256 일치 확인
- Gmail에서 새 제목의 발송·수신 내역 확인

## 제외 범위

- TV 컴퓨터의 원격 조작
- TV 등록 코드 자동 입력
- 기존 Release 태그 이동 또는 덮어쓰기
- 비밀번호·인증코드·API 키의 패키지 포함
