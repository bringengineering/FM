# 청소 광고페이지 문구·상단사진 정리 설계

## 목표

건물 계단·공용부 청소 페이지의 메시지 중복을 없애고, 최상단에서 정장 운영팀의 계단 현장 이미지를 보여준다. 입주·이사청소 페이지는 현재 전환 흐름을 유지하며 회귀만 검증한다.

## 확정 변경

- 건물청소 서비스 카드 구간의 제목을 `계단 한 칸부터 공용창까지 관리합니다.`로 변경한다.
- 해당 구간에 `CLEANING DETAIL`, `서비스 작업 범위` 표기를 함께 사용한다.
- 아래 실제 사진 갤러리는 `실제 작업은 이렇게 진행합니다.`로 제목을 변경해 중복을 없앤다.
- 건물청소에만 최상단 사진으로 `/brand-campaign/bringcare-team-stair-v1.png`를 사용한다.
- 입주·이사청소의 최상단 사진과 페이지 순서는 변경하지 않는다.

## 품질 기준

- 건물청소 페이지에서 새 제목은 한 번만 나타난다.
- 건물청소 최상단 이미지 대체텍스트가 계단의 BRING CARE 운영팀임을 설명한다.
- 입주청소 페이지는 기존 `7개 핵심 청소 구역`, `4단계 진행`, 가격, 견적 폼을 그대로 유지한다.
- PC·모바일에서 이미지가 찌그러지거나 제목이 잘리지 않는다.
