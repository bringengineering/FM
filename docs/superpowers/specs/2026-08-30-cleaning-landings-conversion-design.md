# BRING CARE 청소 광고 랜딩 통합 최적화 설계

## 목표

기존 `계단·공용부 청소`와 `입주·이사청소` 페이지의 사진, 가격, 실제 현장 기록, 견적 폼을 유지하면서 건물관리 페이지에서 확정한 시각 언어와 전환 구조를 이식한다. 두 페이지는 같은 회사로 보이되 검색자의 구매 목적은 서로 다르게 설명한다.

## 공통 디자인 원칙

- 밝은 청회색 단일 배경, 짙은 남색 제목, BRING 블루 포인트를 유지한다.
- 큰 제목, 여유 있는 상하 간격, 둥근 입체 카드, 얇은 테두리와 부드러운 그림자를 사용한다.
- 첫 화면은 사진 위 투명 그라데이션과 굵은 서비스 약속을 결합한다.
- AI 브랜드 캠페인 이미지는 캠페인 이미지로 명확히 구분하고 실제 현장 기록으로 오인시키지 않는다.
- 모든 주요 구간 뒤에 견적 신청 또는 가격 확인 동선을 둔다.

## 계단·공용부 청소

1. 브랜드 소개와 서비스 히어로가 연속으로 반복되는 느낌을 줄이고, 서비스 히어로를 건물청소의 대표 첫 화면으로 강화한다.
2. `건물의 첫인상 관리` 메시지와 월 4회 3층 6만원부터 가격을 첫 화면에서 동시에 이해하게 한다.
3. 8개 작업범위를 건물관리 통합 도식처럼 한눈에 읽히는 범위 요약 허브로 먼저 보여준 뒤 상세 사진 카드로 이어간다.
4. 실제 관리 기록 4건, 기본 포함/별도 작업, 월간보고, 정찰제 가격은 그대로 유지한다.
5. 중간 견적 CTA를 실제 현장 기록과 가격 사이에 추가한다.

## 입주·이사청소

1. 첫 화면은 `입주 전 한 번에 끝내는 구역별 청소`에 집중하고 12만원부터 가격을 함께 보여준다.
2. 창문·욕실·주방·수납장과 바닥·창틀·환기구를 7개 시각 카드와 범위 요약으로 구성한다.
3. 상담 → 범위 확인 → 구역별 작업 → 완료 확인의 4단계 절차를 추가한다.
4. 일반 단건과 관리 건물 가격 차이를 비교 카드로 명확히 보여준다.
5. 검증되지 않은 후기, 별점, 작업 건수는 사용하지 않는다. 대신 구역별 완료 확인과 원주 직영팀 운영을 신뢰 근거로 사용한다.

## 반응형과 접근성

- 데스크톱은 2~4열 시각 구조, 모바일은 단일 열 또는 2열로 재배치한다.
- 모바일에서 제목이 잘리거나 카드가 가로로 넘치지 않게 `word-break: keep-all`과 유동 글꼴 크기를 적용한다.
- 모든 이미지에 목적에 맞는 대체 텍스트를 유지한다.

## 검증 기준

- 두 페이지 모두 서비스별 전용 시각 허브, 중간 CTA, 가격, 최종 견적 폼을 포함한다.
- 건물청소에는 8개 작업범위와 실제 관리 기록 4건이 유지된다.
- 입주청소에는 7개 구역과 4단계 절차가 표시된다.
- 랜딩 테스트 전체, 빌드, PC·모바일 캡처, 공개 URL 응답을 통과한다.
