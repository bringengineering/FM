# BRING TV CMD 전용 설치판 설계

## 목적

TV 컴퓨터에서 반복 실패하는 PowerShell 실행 단계를 완전히 제거하고, Windows CMD만으로 TV 운영보드 자동실행을 등록한다.

## 배포 방식

- 신규 버전: `bring-tv-web-kiosk-v1.0.4`
- 배포 파일: `BRING-TV-CMD-Installer-v1.0.4.zip`
- 기존 v1.0.3 이하 릴리스와 태그는 변경하지 않는다.
- Gmail에는 회사 GitHub의 공개 직접 다운로드 링크를 전송한다.

## ZIP 구성

1. `BRING-TV-설치.cmd`
   - PowerShell을 호출하지 않는다.
   - Edge와 Chrome의 표준 설치 경로를 순서대로 확인한다.
   - 현재 사용자 시작프로그램 폴더에 `BRING-TV-자동실행.cmd`를 복사한다.
   - 설치 직후 자동실행 파일을 호출해 TV 운영보드를 연다.
2. `BRING-TV-자동실행.cmd`
   - 선택된 Edge 또는 Chrome을 키오스크 모드로 실행한다.
   - 전용 브라우저 프로필 경로를 유지해 TV 등록정보를 보존한다.
3. `BRING-TV-삭제.cmd`
   - 시작프로그램에 등록된 BRING TV 자동실행 파일만 제거한다.
   - 브라우저 프로필과 TV 등록정보는 삭제하지 않는다.
4. `사용방법.txt`
   - 압축 해제와 더블클릭 절차를 안내한다.
5. `BRING-TV-설치복구-프롬프트.txt`
   - CMD 오류 기록을 전달하는 안전한 진단 요청문이다.
6. `README.md`
   - 버전, URL, 설치·삭제 동작, 보안 범위를 설명한다.

## 오류 처리

- 오류 기록은 바탕화면의 `BRING-TV-CMD-설치-오류.txt`에 남긴다.
- Edge와 Chrome을 모두 찾지 못하면 설치하지 않고 명확한 오류를 기록한다.
- 시작프로그램 폴더가 없으면 현재 사용자 경로에 생성한다.
- 파일 복사 또는 브라우저 실행 실패 시 종료코드와 실패 단계를 기록한다.
- 관리자 권한을 요구하지 않는다.

## 보안 범위

- PowerShell을 실행하지 않는다.
- 관리자 권한, 비밀번호, 인증코드, API 키를 요구하지 않는다.
- 다른 시작프로그램, 브라우저 자료, CRM 데이터는 변경하거나 삭제하지 않는다.
- TV 운영보드는 기존 HTTPS 주소만 연다.

## 검증 기준

- CMD 파일에 `powershell`, `pwsh`, `.ps1` 문자열이 없어야 한다.
- 설치·자동실행·삭제 파일의 대상 경로와 URL을 자동 테스트한다.
- ZIP에 PowerShell 파일이 포함되지 않아야 한다.
- 공개 다운로드 파일과 로컬 파일의 SHA-256이 일치해야 한다.
- GitHub 검사가 통과해야 한다.
- Gmail에서 v1.0.4 제목의 발송·수신을 확인한다.
