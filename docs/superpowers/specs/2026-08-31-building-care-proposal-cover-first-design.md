# 건물관리 제안서 표지 우선 배치 설계

## 목표

건물관리 페이지의 제안서 신청 영역에서 BRING CARE 제안서 표지를 첫 장처럼 먼저 보여주고, 사용자가 표지와 제안서 성격을 이해한 뒤 신청폼으로 자연스럽게 이동하게 한다.

## 적용 범위

- `#building-care-proposal` 내부 레이아웃만 수정한다.
- 기존 18페이지 PDF와 PDF 다운로드 경로는 유지한다.
- 기존 CRM 제출 값, 동의 절차, 성공 후 다운로드 공개 방식은 유지한다.
- 인증·수상 이력 다음, 최종 상담폼 앞이라는 페이지 위치도 유지한다.

## 레이아웃

1. 제안서 표지를 카드 상단에 전체폭으로 크게 배치한다.
2. 표지는 원본 16:9 비율을 유지하고 `object-fit: contain`으로 잘리지 않게 표시한다.
3. 표지 아래에 `총 18페이지 · PDF` 정보를 배치한다.
4. 그 아래는 데스크톱에서 소개 문구와 신청폼을 2열로, 모바일에서 1열로 배치한다.
5. 신청 성공 시 기존과 동일하게 PDF 다운로드 버튼과 상담 안내를 보여준다.

## 시각 원칙

- 배경과 카드, 테두리, 그림자는 기존 건물관리 페이지의 토스형 디자인을 유지한다.
- 표지가 영역의 첫 시각적 초점이 되도록 너비와 여백을 충분히 확보한다.
- 불필요한 장식이나 새로운 이미지, 새로운 카피는 추가하지 않는다.
- 모바일 390px에서도 가로 넘침이 없어야 한다.

## 검증 기준

- 표지가 신청폼보다 DOM과 화면에서 먼저 노출된다.
- 표지의 계산된 `object-fit`은 `contain`이다.
- 데스크톱과 모바일에서 표지가 잘리지 않는다.
- 기존 CRM 신청 테스트와 성공 후 다운로드 테스트가 계속 통과한다.
- 공개 페이지와 PDF 다운로드 주소가 모두 HTTP 200을 반환한다.
