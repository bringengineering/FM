# BRING CARE 24H 입·퇴실 관리 페이지 상단 재설계

## 목표

`/turnover-care`의 상단 영역을 청소업체형 이미지 상세페이지가 아니라, 실제 서비스를 운영하는 기술 기반 건물관리회사처럼 보이도록 재설계한다.

이번 1차 적용 범위는 내비게이션, 첫 화면, 핵심 운영 과정, 24H 운영 기준 설명까지다. 기존 가격표, 현장기록, FAQ, 상담 폼, CRM 저장, 전화·카카오톡 연결은 기능과 데이터 흐름을 유지한다.

## 승인된 디자인 방향

시각 체계는 다음 네 레퍼런스의 역할을 분리해 적용한다.

- 색상과 브랜드: 기존 BRING CARE 블루·딥블루·화이트
- 글꼴과 메인 문구: LETUS의 Pretendard 기반 체계
- 사진 프레임과 여백: Toss의 큰 단일 프레임과 절제된 내비게이션
- 상담 전환: 청소쾌감의 견적·카카오톡·전화 동선

타사의 로고, 문구, 사진, 소스 코드, 전용 글꼴은 복제하지 않는다. Toss Product Sans 대신 공개 사용 가능한 Pretendard를 사용한다.

## 디자인 토큰

- 기본 글꼴: `Pretendard, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- 브랜드 블루: `#1768FF`
- 딥블루: `#083F91`
- 네이비 오버레이: `#092C5C`
- 본문색: `#191F28`
- 보조 본문색: `#6B7684`
- 연한 테두리: `#E5E8EB`, 1px
- 내비게이션 높이: 64px
- 메인 사진 프레임 모서리: 데스크톱 40px, 모바일 28px
- 일반 버튼 모서리: 12px
- 일반 버튼 높이: 데스크톱 52px, 모바일 50px
- 최대 콘텐츠 폭: 1240px
- 데스크톱 좌우 여백: 24px
- 모바일 좌우 여백: 14px

## 상단 구조

### 내비게이션

- 왼쪽에는 현재 BRING CARE 로고를 둔다.
- 오른쪽에는 `24H 입·퇴실 관리`, `청소 서비스`, `현장 기록`, `30초 견적`을 둔다.
- `30초 견적`만 브랜드 블루 버튼으로 강조한다.
- 모바일에서는 로고와 `30초 견적`만 남긴다.

### 첫 화면

- 실제 BRING CARE 관리 세대 사진을 하나의 큰 배경으로 사용한다.
- 사진 위에 네이비 방향성 오버레이를 적용해 글자를 읽을 수 있게 한다.
- 서비스명은 `BRING CARE 24H 입·퇴실 관리`로 표시한다.
- 제목은 `퇴실 다음 날, 바로 보여줄 수 있는 방으로.`로 한다.
- 보조 설명은 `퇴실 확인부터 직영 청소, 필요한 조치와 완료 사진까지. 다음 임대를 준비하는 과정을 하나로 연결합니다.`로 한다.
- 기본 CTA는 `퇴실 일정 상담하기`, 보조 CTA는 `카카오톡 상담`이다.
- 하단에는 24H 적용 조건과 실제 전화번호 `010-6566-3603`을 노출한다.

### 운영 과정

카드 대신 1px 구분선을 사용한 가로 구조로 다음 네 단계를 표시한다.

1. D-14 사전 접수
2. 퇴실 상태 확인
3. 직영 청소·조치
4. 완료 사진 전달

모바일에서는 2열로 배치하되 같은 정보 순서를 유지한다.

### 24H 설명

제목은 `빠르다는 말보다, 준비된 과정을 보여드립니다.`로 한다.

24H가 무조건적인 시간 보장이나 임대차 계약 보장이 아니라는 점을 짧게 설명하고, 기존 상세 적용 조건 영역으로 연결한다.

## 사진 원칙

- 실제 BRING CARE 현장 사진을 우선한다.
- AI 생성 이미지를 실제 현장처럼 사용하지 않는다.
- 첫 화면 사진은 한 장만 사용하고, 작은 사진 카드나 장식 이미지를 겹치지 않는다.
- 현재 승인 시안에서는 `landing/records/tenancy-check.jpg`를 사용한다.
- 더 좋은 실제 청소·점검 사진이 확보되면 동일한 프레임 안에서 교체할 수 있게 한다.

## 반응형 기준

- 데스크톱에서는 사진과 문구를 한 프레임 안에서 함께 보여준다.
- 모바일에서는 사진 상단, 문구 하단이 자연스럽게 읽히도록 오버레이 방향을 세로형으로 바꾼다.
- 모바일 제목은 약 39px, 본문은 약 15px로 제한한다.
- 모바일 하단에는 모서리 12px의 `퇴실 일정 30초 견적` 고정 버튼을 둔다.
- 작은 화면에서도 24H 적용 조건이 버튼이나 사진에 가리지 않아야 한다.

## 접근성과 검증

- 본문과 배경의 색상 대비를 확인한다.
- 모든 링크와 버튼에 식별 가능한 이름을 제공한다.
- 실제 현장 사진에 구체적인 대체 텍스트를 작성한다.
- 키보드만으로 모든 상담 동선에 접근할 수 있어야 한다.
- 데스크톱과 모바일에서 첫 화면, 전화, 카카오톡, 견적 앵커를 검증한다.
- 기존 CRM 제출 테스트와 `/turnover-care` 렌더링 테스트가 계속 통과해야 한다.
