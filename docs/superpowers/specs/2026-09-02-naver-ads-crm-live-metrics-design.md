# BRING CARE 네이버 광고·CRM 실시간 마케팅 지표 연동 설계

## 목표

현재 광고그룹이 비어 있어 집행되지 않는 네이버 파워링크 캠페인 3개를 10,000원 잔액 안에서 저비용으로 완성한다. 동시에 네이버 광고 실적과 랜딩페이지 상담 문의를 CRM에서 캠페인 단위로 연결해 보고, 기존 AI가 활용할 수 있는 안전한 분석 입력을 만든다.

이번 작업은 다음 두 하위 작업으로 나눈다.

1. 네이버 검색광고 저비용 운영 설정
2. CRM 마케팅 지표 동기화와 AI 분석 입력

## 확인된 현재 상태

- 네이버 광고계정은 `dpvld858`, 광고계정 `2575255`이다.
- `BRING CARE | 입주청소`, `BRING CARE | 건물관리`, `BRING CARE | 계단·공용부청소` 캠페인은 ON·운영가능이다.
- 세 캠페인 모두 광고그룹이 없으므로 실제 광고는 노출되지 않는다.
- 비즈머니 잔액은 10,000원이다.
- 랜딩페이지는 `/move-in-cleaning`, `/building-care`, `/stair-cleaning`으로 분리되어 있다.
- 랜딩 상담폼은 `utm_source`, `utm_campaign`, `utm_term`을 CRM 문의 데이터에 저장한다.
- CRM에는 실시간 광고 문의함이 있으나 광고 매체 성과 데이터 모델과 확인 가능한 AI 공급자 어댑터는 없다.

## 네이버 광고 저비용 운영 설계

### 공통 원칙

- 노출 지역은 원주시로 제한한다.
- 전국형 대표 키워드는 처음에는 등록하지 않는다.
- 원주 지역명이 포함된 긴 검색어만 사용한다.
- 세 광고그룹은 작성 중 OFF 상태를 유지하고 소재·랜딩·추적값 검수 후 한 번에 ON으로 전환한다.
- 비즈머니 자동충전은 사용하지 않는다. 10,000원 잔액을 전체 손실 상한으로 사용한다.
- 30일 동안 낮은 순위에서 천천히 노출하고, 클릭이나 문의가 발생하지 않아도 입찰가를 자동으로 올리지 않는다.

### 캠페인별 초기 설정

#### 입주·이사청소

- 광고그룹: `원주 | 입주·이사청소 | 저비용`
- 초기 최대 입찰가: 1,500원
- 랜딩: `https://bring-fm.web.app/move-in-cleaning?utm_source=naver&utm_medium=cpc&utm_campaign=move_in_cleaning`
- 핵심 키워드: `원주입주청소업체`, `원주원룸청소`, `원주아파트입주청소`, `원주이사청소`
- 운영 우선순위: 1

#### 계단·공용부청소

- 광고그룹: `원주 | 계단·공용부청소 | 저비용`
- 초기 최대 입찰가: 1,000원
- 랜딩: `https://bring-fm.web.app/stair-cleaning?utm_source=naver&utm_medium=cpc&utm_campaign=stair_cleaning`
- 핵심 키워드: `원주계단청소`, `원주건물청소`, `원주빌라청소`, `원주공용부청소`
- 운영 우선순위: 2

#### 건물관리

- 광고그룹: `원주 | 건물관리 | 저비용`
- 초기 최대 입찰가: 800원
- 랜딩: `https://bring-fm.web.app/building-care?utm_source=naver&utm_medium=cpc&utm_campaign=building_care`
- 핵심 키워드: `원주건물관리`, `원주원룸관리`, `원주시설관리`, `원주상가관리`
- 운영 우선순위: 3

### 예산 해석

10,000원을 캠페인별로 강제 분리하는 평생 예산 기능이 없으면 잔액과 일 예산만으로 정확히 5,000원·3,000원·2,000원을 보장할 수 없다. 따라서 다음 원칙을 사용한다.

- 계정 잔액 10,000원을 전체 지출 상한으로 둔다.
- 캠페인별 소진액이 각각 5,000원·3,000원·2,000원에 도달하면 해당 캠페인을 수동 또는 자동 규칙으로 중지한다.
- CRM 대시보드에 캠페인별 배정액·소진액·잔여액을 표시하고 80%, 100% 도달 시 경고한다.

## CRM 실시간 마케팅 지표 설계

### 데이터 흐름

`Naver SearchAd API → Cloud Functions 동기화 → Firebase 마케팅 지표 저장소 → Desktop CRM 대시보드 → AI 분석 입력`

- 서버가 네이버 검색광고 API를 10분마다 호출한다.
- 브라우저나 Electron 렌더러에는 API 비밀키를 전달하지 않는다.
- 네이버 통계 반영 지연 때문에 화면의 `실시간`은 10분 폴링과 네이버 최신 집계시각을 의미한다.
- 동기화 실패 시 마지막 성공 데이터는 유지하고 `지연됨` 상태를 표시한다.

### 저장 데이터

캠페인·일자 단위로 다음 값을 저장한다.

- `campaignId`, `campaignName`, `service`, `date`
- `impressions`, `clicks`, `spend`, `conversions`
- `ctr`, `averageCpc`, `conversionRate`, `costPerLead`
- `allocatedBudget`, `remainingBudget`
- `sourceUpdatedAt`, `syncedAt`, `syncStatus`

상담 문의는 기존 `marketingLeadInbox` 데이터를 재사용하고 `utmCampaign`으로 광고 실적과 연결한다. 네이버 전환 추적이 아직 없더라도 CRM 문의를 자체 전환으로 계산한다.

### CRM 화면

`마케팅 지표` 패널을 추가한다.

- 상단: 오늘 광고비, 노출, 클릭, 문의, 문의당 비용
- 캠페인 카드 3개: 배정액·소진액·클릭·문의·CTR·평균 CPC
- 추세: 최근 7일 비용·클릭·문의
- 동기화 상태: 최신 집계시각, 마지막 성공시각, 오류 여부
- 문의 목록: 기존 광고 문의함을 캠페인별로 필터링

숫자가 없는 경우 0으로 성과를 단정하지 않고 `데이터 없음`, `집계 지연`, `전환 추적 미설정`을 구분한다.

## AI 분석 설계

AI 공급자와 무관한 `marketingInsightSnapshot`을 먼저 생성한다.

- 캠페인별 지표와 최근 7일 변화
- 예산 소진율과 예상 소진일
- 비용은 발생했으나 문의가 없는 키워드
- 문의가 발생한 캠페인·검색어
- 데이터 품질과 표본 부족 경고

AI는 다음 형식으로만 제안한다.

- `유지`: 아직 표본이 부족하거나 비용이 안정적
- `감액 검토`: 비용은 발생했으나 충분한 클릭 뒤 문의가 없음
- `증액 검토`: 문의가 발생했고 문의당 비용이 허용 범위 안임
- `중지 검토`: 관련 없는 검색어나 배정액 한도 도달

AI가 직접 입찰가·예산·ON/OFF를 변경하지 않는다. 모든 변경은 근거 수치와 함께 사용자가 승인해야 한다. 확인 가능한 기존 AI 어댑터가 발견되지 않으면 같은 데이터로 규칙 기반 인사이트를 먼저 표시하고, 공급자 어댑터는 별도 연결한다.

## 보안과 실패 처리

- 네이버 API 고객번호·Access License·Secret Key는 서버 비밀값으로만 저장한다.
- 동기화 함수는 읽기 전용 통계 API만 사용한다.
- 동일 날짜·캠페인 데이터는 멱등적으로 덮어써 중복 합산을 방지한다.
- 네이버 API 오류·한도 초과·자격증명 만료를 서로 다른 상태로 기록한다.
- CRM은 마지막 정상 데이터와 오류 상태를 동시에 표시한다.

## 검증 기준

### 광고계정

- 세 캠페인에 광고그룹·키워드·소재·전용 랜딩 URL이 존재한다.
- 원주시 지역 타기팅과 낮은 초기 입찰가가 적용된다.
- 자동충전이 비활성화되어 있다.
- 잔액 10,000원 이상으로 추가 지출할 수 없다.

### 데이터 동기화

- 네이버 원본 대시보드와 CRM의 노출·클릭·비용 합계가 같은 집계시각에서 일치한다.
- CTR은 `클릭수 / 노출수`, 평균 CPC는 `비용 / 클릭수`로 0 분모를 안전하게 처리한다.
- 같은 데이터를 두 번 동기화해도 합계가 증가하지 않는다.
- UTM 캠페인이 있는 상담 문의가 올바른 캠페인에 연결된다.

### AI

- 표본이 부족할 때 증액·중지 결론을 단정하지 않는다.
- AI 제안은 실제 광고 설정을 자동 변경하지 않는다.
- 데이터 지연이나 누락이 있으면 제안보다 경고를 우선한다.

## 구현 순서

1. 네이버 광고그룹·키워드·소재를 OFF 상태로 구성하고 검수한다.
2. 네이버 SearchAd API 자격증명과 읽기 전용 동기화 함수를 연결한다.
3. Firebase 마케팅 지표 모델과 CRM 대시보드를 구현한다.
4. UTM 상담 문의를 캠페인 실적과 결합한다.
5. 규칙 기반 인사이트를 먼저 검증한 뒤 기존 AI 어댑터를 연결한다.
6. 원본 네이버 수치와 CRM 수치를 대조한 후 광고그룹을 ON으로 전환한다.
