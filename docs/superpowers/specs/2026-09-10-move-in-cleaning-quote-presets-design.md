# 입주청소 견적 표준 품목·가격 선택 설계

## 목적

CRM 견적서에서 입주청소 견적을 작성할 때 담당자마다 품목과 설명이 달라지지 않도록 표준 5개 품목을 고정한다. 사용자는 10만원부터 20만원까지 총액을 선택하고, CRM은 선택 금액을 정해진 비율로 각 품목에 자동 배분한다.

## 적용 범위

- 견적서의 작업 종류가 `입주청소`일 때만 적용한다.
- AI 작성과 수기 작성 모두 같은 표준 품목을 사용할 수 있게 한다.
- 다른 작업 종류의 견적 생성 방식은 변경하지 않는다.
- 자동 생성 후에는 기존처럼 품목명·세부 내용·금액을 직접 수정할 수 있다.

## 화면과 동작

1. 견적서 작성 화면에서 `입주청소 표준 견적`을 선택한다.
2. 총액 선택란에 10만원부터 20만원까지 1만원 단위의 선택지를 표시한다.
3. 금액을 선택하면 표준 5개 품목, 수량 `1`, 단위 `식`, 세부 내용과 배분 금액을 즉시 반영한다.
4. 합계와 미리보기는 선택과 동시에 갱신한다.
5. 사용자가 자동 생성된 값을 직접 수정하면 기존 견적서 편집 규칙에 따라 수정값을 유지한다.

## 표준 품목

| 품목 | 규격 및 세부 내용 | 비율 |
|---|---|---:|
| 내부 기본 청소 | 천장·벽면·몰딩·문·문틀·스위치·콘센트의 먼지 및 생활 오염 제거, 실내 바닥 진공청소 및 물걸레 마감 | 25% |
| 주방 청소 | 싱크대·상판·수납장 내외부·후드 외부·가스레인지 주변의 먼지와 일반 기름때 제거 및 표면 세척 | 20% |
| 욕실 청소 | 변기·세면대·거울·수전·타일·배수구 세척, 일반 물때와 표면 오염 제거 및 위생 마감 | 20% |
| 창호·베란다 청소 | 내부 유리·창틀·창호 레일의 먼지와 오염 제거, 베란다 바닥 및 배수구 주변 청소 | 20% |
| 마감·소모품·장비비 | 청소 상태 최종 점검, 잔여 오염 부분 보완, 작업 폐기물 정리 및 세제·소독제·청소도구 사용 | 15% |

10만원 선택 시 금액은 각각 25,000원, 20,000원, 20,000원, 20,000원, 15,000원이다. 다른 선택 금액에도 같은 비율을 적용하며 다섯 품목의 합계는 선택 총액과 정확히 일치해야 한다.

## 금액 계산

- 선택 가능 금액: 100,000원부터 200,000원까지 10,000원 단위
- 배분 비율: 25%·20%·20%·20%·15%
- 원 단위 반올림 때문에 차이가 발생하면 마지막 품목에 차액을 반영해 합계를 맞춘다.
- VAT 포함 총액으로 처리하는 기존 견적서 계산 규칙을 유지한다.

## 기본 안내 사항

- 외창, 심한 곰팡이, 스티커·접착제, 대량 폐기물 및 가전 내부 청소는 기본 범위에서 제외한다.
- 현장 상태와 오염도에 따라 추가 비용이 발생할 수 있음을 견적서 안내 사항에 표시한다.

## 오류 처리

- 선택 범위를 벗어난 금액은 표준 견적 선택값으로 받지 않는다.
- 표준 품목 생성에 실패하면 기존 견적 내용을 지우지 않고 오류를 표시한다.
- 표준 견적을 다시 적용할 때는 현재 품목이 교체됨을 사용자가 알 수 있게 한다.

## 검증 기준

- 100,000원부터 200,000원까지 모든 선택 금액에서 품목이 정확히 5개 생성된다.
- 각 품목명과 세부 내용은 표준 문구와 일치한다.
- 모든 금액에서 품목 합계가 선택 총액과 일치한다.
- 100,000원 선택 시 25,000원·20,000원·20,000원·20,000원·15,000원이 생성된다.
- AI가 다른 입주청소 품목을 반환해도 표준 품목이 우선 적용된다.
- 사용자가 생성 후 각 값을 직접 수정할 수 있다.
- 다른 작업 종류의 견적 생성 결과는 바뀌지 않는다.
