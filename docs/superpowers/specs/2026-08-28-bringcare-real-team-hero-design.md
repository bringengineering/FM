# 브링케어 실제 팀 촬영형 히어로 이미지 설계

## 목적

브링케어 광고 페이지 초입에서 전원이 정장을 입은 한국인 팀이 관리 건물 앞에서 함께 촬영한 듯한 신뢰를 전달한다. 청소 작업 장면이 아닌 홈페이지 상단용 공식 단체사진이며, 실제 직원 기록이 아니라 브링케어의 운영팀을 표현한 브랜드 캠페인 이미지로 사용한다.

## 핵심 메시지

메인 문장: `브링케어는 건물을 관리하며, 청소까지 직접 수행합니다.`

보조 문장: `관리자가 현장에 있습니다.`

브랜드 문장: `건물을 대하는 태도부터 다릅니다.`

## 대표 이미지

- 원주의 현실적인 중소형 원룸·다가구 건물 정면을 배경으로 한다.
- 한국인 남녀 8~10명이 건물 입구 앞에서 카메라를 바라보며 한 팀으로 모여 선다.
- 연령은 20대 후반부터 50대 초반까지 섞는다.
- 전원이 검은색 또는 짙은 네이비 비즈니스 정장, 흰색·연한 하늘색 셔츠와 절제된 넥타이를 착용한다. 작업복과 캐주얼 복장은 사용하지 않는다.
- 일부 인원만 깨끗한 청소도구 또는 태블릿을 자연스럽게 들고, 나머지는 손을 모으거나 편안하게 선다. 실제 청소 동작은 하지 않는다.
- 회사 공식 단체사진이되 지나치게 경직되지 않도록 표정·어깨 높이·체형·정장 핏을 서로 다르게 표현한다.
- 흐린 날의 부드러운 자연광, 낮은 대비, 35mm 다큐멘터리 사진, 절제된 색감과 미세한 필름 입자를 사용한다.
- 피부결, 잔머리, 옷 주름과 건물 표면을 과도하게 보정하지 않아 실제 촬영 사진처럼 보이게 한다.
- 과도한 보케, HDR, 플라스틱 피부, 완벽한 좌우대칭, 반복 얼굴, 비현실적인 손을 피한다.
- 광고 모델처럼 과장된 미소, 모두 같은 자세, 지나치게 완벽한 치아와 얼굴 비율을 피한다.
- 이미지 안에는 글자·로고·워터마크를 생성하지 않는다. 웹 텍스트는 HTML로 별도 배치한다.

## 보조 이미지

- 이번 교체 범위에서는 보조 이미지를 새로 만들지 않는다. 상단 가로형 단체사진 한 장의 완성도에 집중한다.

## 웹 적용

- 대표 이미지는 건물관리 중심 페이지의 초입 히어로 후보로 사용한다.
- 입주청소 페이지에는 전체 교체가 아니라 신뢰 섹션의 팀 소개 이미지로 제한한다.
- 이미지 인접 위치에 `브링케어 브랜드 캠페인 이미지`를 작은 캡션으로 표시한다.
- 실제 현장사진과 실제 관리실적 섹션은 별도로 유지한다.

## 검수 기준

- 처음 봤을 때 AI 광고보다 실제 한국 회사가 관리 건물 앞에서 촬영한 공식 단체사진처럼 느껴지는가.
- 8~10명 전원이 정장을 입고 있으며 작업복 인원이 섞이지 않았는가.
- 청소 작업 장면이 아니라 한 팀으로 모여 선 상단용 단체사진인가.
- 팀이 지나치게 크거나 대기업처럼 보이지 않는가.
- 건물관리와 현장 청소를 함께 수행하는 조직이라는 인상이 드는가.
- 손·얼굴·눈·치아·인원 배치에 명백한 생성 오류가 없는가.
- 실제 직원사진 또는 실제 실적으로 오해시키는 표현이 없는가.
