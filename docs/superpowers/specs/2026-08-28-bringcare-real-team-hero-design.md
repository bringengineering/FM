# 브링케어 실제 팀 촬영형 히어로 이미지 설계

## 목적

브링케어 광고 페이지 초입에서 회사를 실제 운영하는 한국인 팀이 현장 건물 앞에 모여 촬영한 듯한 신뢰를 전달한다. 이미지는 실제 직원 기록이 아니라 브링케어의 운영팀을 표현한 브랜드 캠페인 이미지로 사용한다.

## 핵심 메시지

메인 문장: `브링케어는 건물을 관리하며, 청소까지 직접 수행합니다.`

보조 문장: `관리자가 현장에 있습니다.`

브랜드 문장: `건물을 대하는 태도부터 다릅니다.`

## 대표 이미지

- 원주의 현실적인 중소형 원룸·다가구 건물 정면을 배경으로 한다.
- 한국인 남녀 8~12명이 건물 입구 앞에 자연스럽게 모여 선다.
- 연령은 20대 후반부터 50대 초반까지 섞는다.
- 관리직 정장 30%, 셔츠·니트·슬랙스 40%, 네이비 현장 작업복 30%로 구성한다.
- 모두 동일한 포즈를 취하지 않는다. 일부는 손을 모으고, 일부는 가볍게 팔짱을 끼고, 일부는 동료 쪽으로 몸을 기울인다.
- 회사 워크숍에서 전문 사진가가 한 번에 촬영한 듯한 자연스러운 표정과 현실적인 피부·체형·옷 주름을 유지한다.
- 맑지만 약간 흐린 자연광, 35mm 다큐멘터리 사진, 미세한 필름 입자를 사용한다.
- 과도한 보케, HDR, 플라스틱 피부, 완벽한 좌우대칭, 반복 얼굴, 비현실적인 손을 피한다.
- 이미지 안에는 글자·로고·워터마크를 생성하지 않는다. 웹 텍스트는 HTML로 별도 배치한다.

## 보조 이미지

- 같은 팀이 건물 내부 계단과 난간에 자연스럽게 흩어져 위쪽 카메라를 바라보는 세로 구도다.
- 대표 이미지와 인원·연령·복장 체계를 유지하되 동일 인물 재현을 보장한다고 표현하지 않는다.
- 팀 규모와 현장성을 전달하는 보조 캠페인 이미지로만 사용한다.

## 웹 적용

- 대표 이미지는 건물관리 중심 페이지의 초입 히어로 후보로 사용한다.
- 입주청소 페이지에는 전체 교체가 아니라 신뢰 섹션의 팀 소개 이미지로 제한한다.
- 이미지 인접 위치에 `브링케어 브랜드 캠페인 이미지`를 작은 캡션으로 표시한다.
- 실제 현장사진과 실제 관리실적 섹션은 별도로 유지한다.

## 검수 기준

- 처음 봤을 때 AI 광고보다 실제 한국 회사 단체사진처럼 느껴지는가.
- 팀이 지나치게 크거나 대기업처럼 보이지 않는가.
- 건물관리와 현장 청소를 함께 수행하는 조직이라는 인상이 드는가.
- 손·얼굴·눈·치아·인원 배치에 명백한 생성 오류가 없는가.
- 실제 직원사진 또는 실제 실적으로 오해시키는 표현이 없는가.
