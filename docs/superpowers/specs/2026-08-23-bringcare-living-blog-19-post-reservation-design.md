# 브링케어 생활형 블로그 19편 예약 발행 설계

## 목표

2026년 8월 23일 공개한 `냉장고 리뷰 보기 전에, 용량보다 먼저 재야 할 곳이 있습니다`의 글 품질과 네이버 편집 방식을 기준으로, 원본 주제표의 남은 19개 주제를 제작해 3시간마다 1편씩 예약 발행한다.

## 발행 일정

- 첫 예약 시각: 2026년 8월 23일 오전 4시(Asia/Seoul). 준비가 이 시각을 넘기면 이후 가장 가까운 정시 슬롯부터 시작한다.
- 기본 간격: 밤과 새벽을 포함해 3시간마다 1편
- 전체 기간: 19편 기준 약 54시간
- 기본 순서: 원본 목록의 2번부터 20번까지
- 시기형 주제: `9월 마트 휴무일`과 `추석 전 대청소 순서`도 목록 순서대로 예약하되, 발행 준비일의 공식 일정과 달력을 다시 확인하고 제목·본문을 실제 시점에 맞춘다.
- 네이버 예약 한도나 편집기 제약이 있으면 가능한 범위까지 우선 예약하고, 남은 글은 원고·자산·예정 시간을 보존해 후속 회차에서 이어간다.

## 조사와 사실 검증

- 제품별 청소·관리 주기는 제조사 공식 설명서와 공식 고객지원 페이지를 발행 준비일에 확인한다.
- 폐기·신고 방법은 대한민국 공식 행정기관 자료를 확인하고 지역별 차이를 명시한다.
- 마트 휴무일은 해당 월의 공식 점포 안내를 확인하며, 확인되지 않은 일정을 추정하지 않는다.
- 세제 혼합, 전기제품 분해, 곰팡이 제거 등 안전 문제가 있는 글은 위험한 자가 조치를 권하지 않는다.
- 가격·효과·후기·사용 경험은 확인 자료가 없으면 만들지 않는다.

## 이미지 원칙

1. 대한민국에서 촬영된 실제 사진이며 재사용 권리가 확인되는 자료를 우선한다.
2. 제조사 공식 보도자료 사진은 해당 게시물의 이용 조건을 확인한 경우에만 사용한다.
3. 공공누리·공식 기관·직접 촬영·상업적 재사용이 허용된 국내 사진을 우선 탐색한다.
4. 사진 저작자·라이선스·원문 URL은 내부 브리프에 기록하되 공개 본문 하단에 라이선스 덤프로 넣지 않는다.
5. 적합한 실사진을 확보하지 못한 정보형 글만 설명용 AI 이미지로 전환하고 네이버 AI 활용 표시를 켠다.
6. AI 이미지를 실제 작업·고객 사례·전후 사진으로 표현하지 않는다.

## 글 품질과 편집 형식

- 첫 5문장에 구체적인 생활 장면, 감정, 예상 밖의 문제, 읽어야 할 질문을 넣는다.
- 제목의 검색 질문을 본문에서 충분히 해결한다.
- 제공되지 않은 경험이나 현장 사례를 만들지 않는다.
- 제목 외 모든 본문 문단을 가운데 정렬한다.
- 하나의 문장 또는 완결된 의미 묶음이 끝나면 빈 문단을 둔다.
- 소제목은 이모티콘 1개, 굵게, 밑줄, 한 가지 색상 또는 연한 배경색으로 구분한다.
- 핵심 판단 인용구 1~3개, 네이버 실제 구분선 3~5개를 내용 전환 지점에 사용한다.
- 필요한 사진을 관련 문단 가까이에 분산하고 모든 사진에 짧은 캡션을 단다.
- 태그는 네이버 태그 입력란에만 등록한다.
- 공개 본문 하단에 출처·확인일·URL·사진 라이선스·연락처 덤프를 넣지 않는다.

## 콘텐츠 엔진과 CTA

- 기본적으로 생활 검색형 `traffic` 글로 제작하며 회사소개·상담 문단·상담 배너를 넣지 않는다.
- 승인된 상품과 주제가 직접 맞는 경우에만 `affiliate`로 전환하고 정확한 광고 고지와 승인 링크만 사용한다.
- 실제 브링케어 현장 자료가 추가 제공된 경우에만 `brand_field`로 전환한다.
- 한 글의 행동은 저장·관련글·승인된 구매·상담 중 하나만 사용한다.

## 제작·예약 흐름

각 글은 `주제 조사 → 공식 근거 확인 → 실제 사진·권리 탐색 → 브리프 작성 → 원고 작성 → validate_brief.py → validate_draft.py → 네이버 편집 적용 → 예약 설정 → 예약 화면 재검수 → 원장 기록` 순으로 처리한다.

## 실패 처리

- 로그인 만료, CAPTCHA, 정책 경고, 편집기 구조 변경, 예약 한도, 사실 검증 실패, 이미지 권리 불명확이 발생하면 해당 글의 예약을 중단한다.
- 이미 예약된 다른 글은 임의로 삭제하거나 변경하지 않는다.
- 중단 단계와 필요한 사용자 조치, 재개 지점을 `blog/automation/alerts.md`와 backlog에 기록한다.

## 완료 기준

- 19개 글마다 브리프·원고·이미지 권리 기록과 검증 결과가 존재한다.
- 네이버 예약 목록에서 제목·예약 시각·카테고리·공개 범위가 확인된다.
- 실제 편집 화면에서 가운데 정렬, 문단 여백, 강조, 인용구, 구분선, 이미지·캡션, AI 표시, 태그를 검수한다.
- 예약된 글과 다음 순번을 backlog와 성과 원장에 기록한다.
