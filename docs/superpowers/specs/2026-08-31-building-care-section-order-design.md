# BRING CARE 건물관리 페이지 신뢰·협력 섹션 재배치

## 목표

서비스 이해와 전환 흐름을 먼저 보여주고, 기업 인증과 수상·교육 이력은 최종 상담 직전의 신뢰 근거로 배치한다. 이지부동산중개법인 협력은 공실·입퇴실 관리 맥락에서 바로 인지되도록 강화한다.

## 확정 배치

1. 상단 팀 소개 다음에는 고객 문제와 통합관리 설명이 이어진다.
2. 상단에 있던 `CertificationTrustBar`와 `BuildingCareCredentials`를 제거한다.
3. 이지부동산중개법인 협력 섹션은 `24H 입·퇴실 관리` 소개 바로 다음에 배치한다.
4. 통합관리 도식의 공실 항목에는 `이지부동산중개법인 임대차 중개 연계`를 명시한다.
5. 페이지 하단 순서는 `FAQ → 공식 기업 인증·수상·교육 이력 → 무료 관리진단 신청`으로 구성한다.
6. 최종 상담·견적 신청 섹션은 페이지의 마지막 전환 지점으로 유지한다.

## 협력 문구

- 제목: `공실 관리부터 임대차 중개 연계까지`
- 역할 구분: `건물관리는 BRING CARE가, 임대차 중개는 이지부동산중개법인이 담당합니다.`
- 부동산 중개 업무는 협력 법인이 담당한다는 점을 명확히 표시한다.

## 검증 기준

1. 인증·수상 섹션이 FAQ 뒤, 최종 상담 앞에 표시된다.
2. 이지부동산중개법인 협력 섹션이 입·퇴실 패키지 바로 뒤에 표시된다.
3. 통합관리 도식에서 이지부동산중개법인 명칭을 확인할 수 있다.
4. 데스크톱과 모바일에서 가로 넘침이 없다.
5. 기존 견적 신청과 카카오톡 상담 기능이 유지된다.
