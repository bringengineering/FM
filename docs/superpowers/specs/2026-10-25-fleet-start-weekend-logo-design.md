# 차량대장 출차·주말예약·브랜드 적용 설계

## 목표

운행 시작 입력을 실제 직원 사용 방식에 맞게 단순화하고, 주말 공용차 사용은 승인된 예약만 허용한다. Google Drive의 브링엔지니어링 공식 로고는 투명 배경 자산으로 정리해 PWA와 관리자 화면에 동일하게 적용한다.

## 결정 사항

### 운행 시작 입력

- 운행 목적은 고정 선택 목록 대신 자유 입력 텍스트로 받는다.
- 운행 목적과 목적지는 공백만 입력할 수 없으며 각각 필수다.
- 출발 km는 선택 입력이다. 비어 있으면 서버에 저장된 차량 현재 km를 자동 사용한다.
- 출발 계기판 사진은 필수다. 카메라 촬영 또는 휴대폰 사진 선택을 지원하되 이미지가 없으면 제출되지 않는다.
- 사진은 기존 방식대로 브라우저에서 최대 1280px JPEG로 압축해 Realtime Database에 저장한다.

검토한 대안은 `선택 목록 + 기타 입력`, `자유 입력`, `최근 목적 자동완성` 세 가지다. 이번에는 자유 입력을 채택한다. 업무 종류가 고정되지 않아 선택 목록 유지 비용이 크고, 최근 목적 자동완성은 사용 데이터가 쌓인 뒤 추가하는 편이 낫다.

### 주말 예약

- 토요일과 일요일 운행은 사전 예약 및 관리자 승인을 필수로 한다.
- 예약 시간대가 겹치는 승인·대기 예약은 새로 신청할 수 없다.
- 주말에 운행 시작을 누르면 현재 사용자에게 현재 시각을 포함하는 승인 예약이 있는지 확인한다.
- 승인 예약이 없으면 운행을 시작하지 않고 예약 화면으로 안내한다.
- 평일 단거리 운행은 기존처럼 즉시 출차할 수 있다.
- 장거리·외부 반출은 요일과 관계없이 기존 승인 대상이다.
- 관리자 승인 시점에도 중복 여부를 다시 검사해 경합 승인을 막는다.

검토한 대안은 `빈 시간이면 자동 확정`, `관리자 승인`, `선착순 슬롯`이다. 팀 합의와 기존 혼합형 정책에 맞춰 관리자 승인을 채택한다.

### 회사 로고

- Google Drive에서 브링엔지니어링 공식 로고 원본을 파일명·미리보기로 확인한다.
- 가능하면 벡터 또는 이미 투명한 PNG 원본을 우선 사용한다.
- 배경이 있는 래스터 이미지만 존재하면 배경을 제거하고 가장자리와 내부 글자를 시각 검수한다.
- 결과물을 `company-site/public/fleet/`에 넣고 상단 브랜드, 로그인 화면, PWA 아이콘에 적용한다.
- 원본 비율은 유지하며 다크·라이트 배경에서 식별 가능하도록 여백과 크기만 CSS로 조정한다.

## 데이터와 보안규칙

- `Trip.startOdometer`는 최종 저장 시 항상 숫자다. UI에서 누락된 경우 현재 차량 km로 변환한다.
- `Trip.purpose`, `Trip.destination`, `Trip.evidenceUrl`은 운행 생성 시 필수다.
- 주말 출차 검사는 클라이언트 UX와 Firebase 규칙/서버 데이터 검증을 함께 사용한다.
- 예약은 `startAt < endAt`이어야 하며, 중복 판정은 `[startAt, endAt)` 반개구간으로 처리한다.
- viewer는 읽기 전용, member는 본인 신청·본인 운행, admin은 승인·반려 권한을 유지한다.

## 오류 처리

- 목적·목적지가 비었거나 사진이 없으면 각 입력 아래에 한국어 오류를 표시한다.
- 사진 처리 실패 시 제출을 중단하고 재촬영 안내를 표시한다.
- 주말 승인 예약이 없으면 `주말 운행은 승인된 예약이 필요합니다`를 표시하고 예약 화면 이동 버튼을 제공한다.
- 중복 예약은 겹치는 예약자 이름을 노출하지 않고 `이미 예약된 시간입니다`로만 안내한다.

## 검증

- 운행 목적 자유 입력, 목적지 필수, 출발 km 자동 대체, 사진 필수에 대한 컴포넌트·도메인 테스트를 먼저 실패시킨다.
- 주말 승인 예약 유무 및 시간 중복 판정 단위 테스트를 추가한다.
- Firebase 에뮬레이터로 익명/열람자 차단, 직원 본인 예약·운행, 관리자 승인 권한을 재검증한다.
- 모바일 화면에서 카메라 필수 표시와 로고 렌더링을 확인한다.
- 전체 빌드·린트·규칙 테스트 후 PR 병합, Firebase Hosting/Database Rules 배포, 운영 URL 재확인을 수행한다.
