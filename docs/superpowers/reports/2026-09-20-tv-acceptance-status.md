## 다음 진행 순서

1. 현재 코드의 GitHub 검사 완료 확인. 최신 검사 실행은 `35453490121`이며 결과를 별도 확인해야 한다.
2. TV 전용 업데이트 경로·서명 정책을 정하고 구현한다. 기존 CRM 업데이트 피드에 TV 설치본을 절대 넣지 않는다. 기존 태그 이동/재사용 금지.
3. 실제 운영 반영 시점을 확정한 뒤 CRM 관리자 화면을 배포한다. Firebase Functions/Hosting은 배포하지 않는다.
4. 사용자가 TV Windows 컴퓨터에서 설치를 실행하거나, 이미 승인된 원격 접속 방식을 제공한다. 새 원격지원 프로그램·자동 로그인·시작프로그램 등록은 임의 수행하지 않는다.
5. 관리자 로그인으로 기기 승인, 게시, 원격 편성 변경, 재시작 후 인증 유지, 연결 해제를 실제 TV에서 확인한다.
6. 현장 720p/1080p 가독성 및 실제 설치 버전에서 자체 업데이트를 검증한다.

버전 보고 기능은 서버를 먼저 배포한 다음 새 TV 설치본에 적용한다. 현재 배포된 서버는 `clientVersion` 요청 필드를 아직 허용하지 않으므로 새 클라이언트를 먼저 운영 실행하지 않는다. 기존 클라이언트의 빈 요청은 새 서버에서도 그대로 허용한다.
