# BRING TV Windows 검증용 설치본

## 현재 상태

- Windows x64 설치본: `desktop-crm/dist-tv/BRING.TV.Preview.Setup.0.1.0.exe`
- 버전: TV 전용 0.1.0. CRM 1.8.0과 다른 프로그램입니다.
- 기존 CRM의 설치 이름, 프로그램 ID, 데이터 폴더와 분리했습니다.
- 설치 후 자동 실행하지 않습니다. 현재 컴퓨터에는 설치하지 않았습니다.
- 실제 배포 서버 연결은 아직 활성화되지 않았으므로 현재는 운영 사용 준비가 끝난 상태가 아닙니다.

## 확인한 것

- Windows 설치본과 blockmap 빌드 성공.
- 크기 94,878,932바이트. Authenticode 상태 `NotSigned`: 서명되지 않은 검증용이며 보안 경고 우회를 권장하지 않습니다.
- SHA-256: `1A2A99DDCABCEDCE5E12393F69C78B408CA23D9DDF64ECAA2CB8303AC1646AA5`
- 압축된 앱의 시작 파일이 TV 전용 파일인지 확인.
- 소스 파일 13개가 지정된 TV 화면·보호 연결·스타일 파일만 포함하는지 확인.
- CRM 메인 프로그램, 직원 로그인 저장 파일, TV 기기 인증 저장 파일은 설치 패키지에 포함되지 않음.
- 기존 CRM의 GitHub 자동 업데이트 배포 경로를 사용하지 않음. TV 자동 업데이트는 아직 연결되지 않음.

## 운영 전 필수 확인

1. 회사 Cloudflare 계정과 대상 확인 후 TV 저장소·요청 제한 설정 및 서버 활성화.
2. Windows 보호 저장소의 실제 저장·재실행 검증.
3. TV 컴퓨터에 설치 후 표시된 코드를 관리자 프로그램에서 승인.
4. 업무 실적과 공지 게시 → TV 수신 확인 → 프로그램 재시작 → 권한 회수 확인.
5. 720p/1080p 및 TV 실제 배율에서 글자 잘림과 가독성 확인.
6. 회사에서 관리할 서명·업데이트 배포 경로 결정 및 검증. 기존 CRM 릴리스와 혼합하지 않음.

자동 실적 게시를 켠 관리자 컴퓨터의 프로그램이 실행 중이어야 실적이 갱신됩니다. 화면 이동은 가능하지만 관리자 프로그램 종료 후까지 갱신되는 상시 클라우드 작업은 아닙니다. 변경사항을 모두 검증하기 전 실제 운영용으로 배포하지 않습니다.
