# 기존 분기 목표를 프로젝트에 연결하는 첫 구현

목표: 삭제되거나 보이지 않던 기존 `crmCompany/objectives`의 **활성·현재 분기** 목표를 CRM 프로젝트 홈과 해당 프로젝트 개요에서 읽기 전용으로 연결한다. 기존 ID·KR·프로젝트 링크는 변경하지 않는다.

1. 분기/목표/KR의 안전한 읽기 투영을 테스트한다. 누락·오류를 `0%`로 만들지 않고 `연결 확인 필요`로 남긴다. 연락처 같은 고객정보는 별도 TV 투영에 사용하지 않는다.
2. 기존 `loadWorkOrders`에 목표 읽기를 추가한다. 권한/연결 오류는 목표의 `available=false`로 분리해 기존 업무 조회를 중단하지 않되, 화면에서 빈 목록으로 오인하지 않는다.
3. 프로젝트 홈에 이번 분기 목표 카드, 실제 프로젝트 개요에 해당 목표 링크를 표시한다. 목표를 누르면 기존 프로젝트로 이동하며 사용자가 입력한 업무 초안은 보존한다.
4. 관련 단위·연결 테스트, 전체 CRM 테스트를 실행하고 검토 요청에 반영한다.

이번 단위에서 목표의 저장·수정, 기존 데이터 자동 이동, 연간/반기 목표 신설, TV 게시, 매출 수치 생성은 하지 않는다. 후속 단위는 회사의 승인된 원천/공개 범위와 별도 검증이 필요하다.
