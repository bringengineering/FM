# 브링케어 네이버 블로그 홈 디자인 제작 계획

**목표:** 건물주를 최우선 대상으로 하되 일반 방문자도 이해할 수 있는 네이버 블로그 홈 디자인 5종을 완성한다.

**기준 문서:** `docs/superpowers/specs/2026-08-23-bringcare-blog-home-brand-design.md`

## 산출물

- 상단 커버 마스터: 2560×960 PNG
- 상단 커버 게시용: 1920×640 PNG
- 프로필 이미지: 1024×1024 PNG
- 카테고리 이미지 3종: 각 1080×1080 PNG
- 전체 미리보기 시트
- 제미나이 재생성용 프롬프트 문서

## 작업 순서

1. 기존 브링케어 자료에서 깨끗한 로고 원본 또는 추출 가능한 고해상도 로고를 찾는다.
2. 실제 한국 소형 임대건물 관리 현장을 표현하는 이미지 배경을 생성한다.
3. 생성 배경에는 글자·주소·로고·워터마크를 넣지 않는다.
4. 브링케어 로고와 정확한 한글 문구를 별도 합성해 브랜드 일관성을 확보한다.
5. 네이버 블로그 크롭을 고려해 커버 핵심 요소를 중앙 안전영역에 배치한다.
6. 최종 파일의 크기, 맞춤법, 색상, 가독성, 개인정보 노출 여부를 점검한다.

## 핵심 문구

- 메인: `건물 관리의 모든 것, 브링케어`
- 서브: `현장 확인부터 완료 보고까지`
- 업무 범위: `공실관리 · 세입자 응대 · 청소 · 수리조율 · 사진보고`
- 카테고리: `생활 속 관리정보`, `브링케어 현장기록`, `건물주 관리가이드`

## 검수 기준

- 모든 한글 문구가 정확하고 작은 화면에서도 읽힌다.
- 로고는 AI가 재생성한 형태가 아니라 기존 브랜드 자산을 사용한다.
- 건물 관리 업체라는 인상이 첫 화면에서 즉시 전달된다.
- 공사·건설 현장처럼 보이지 않고, 운영·점검·청소·보고 중심으로 보인다.
- 인물 얼굴과 주소 등 식별 가능한 개인정보가 노출되지 않는다.
