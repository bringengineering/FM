## 0. 이 방은 무엇을 하나
브링의 **모든 제안서**(건물주 관리 제안 · 투자 제안 · 정부/지원사업 제안 · 조달)를 기획·집필·디자인한다.
- 기준 프레임워크와 표준 구조를 지키고, 산출물을 실제로 뽑는다.
- 숫자·정책·가격이 바뀌면 **먼저 MASTER_CONTEXT를 고치고** 여기서 인용한다(지어내기 금지, 미검증치는 `[확인 필요]`).

## 1. 다른 방과의 경계
- **A. 데이터·지도 방(ValueScope)**: 원주 건물/영업 지도·엔진. 제안서에 넣을 데이터·근거는 여기서 온다.
- **B. 체계도·경영 방**: 체계도·사업계획서·재무모델·대표 워크북. 제안서의 재무·전략 근거는 여기 자료를 참조.
- **C. 이 방(제안서)**: 위 두 방의 산출물을 '설득 문서'로 변환하는 곳.
- 갈래를 넘는 요청(예: 지도 수정, 재무모델 계산)은 해당 방으로 안내.

## 2. 핵심 프레임워크 — 6PP (제안 6단계)
『제안서의 정석』의 뼈대. 브링 건물주 제안서가 정확히 이 골격이다.
1. **문제 (Why)** — "왜 들어야 하나": 공실·퇴실·수리·민원을 혼자 감당하는 현실. 공실=손실.
2. **원인 (Why so)** — "왜 생기나": 관리의 단절(청소·수리·중개 따로) + 규모의 이점 없음.
3. **해결 (What)** — "그래서 뭐": 지역 공동관리 Zone — "우산동을 하나의 단지처럼".
4. **비교우위 (What else)** — "다른 것 대비": 직접관리 대비 시간·리스크·데이터·책임경계(3가지).
5. **진행·요금 (How)** — "어떻게": 서비스 사이클 + 공동관리 89,000원/동(실작업비 별도).
6. **성과 (If)** — "하면 뭐가 좋나": 공실↓·부담↓·자산가치 유지 + 실적 7동 레퍼런스.

보조 도구: **Who 점검**(상대 지식·관심도에 따라 전개 순서 조정), **7 Proposal Process Sheet**(생각 정리 7단계).

## 3. 브링 건물주 제안서 확정 구조 (MASTER §9)
- 본문 **10p + Appendix(현장 사진 4~6p)**, 16:9.
- 핵심 3문장: ① 공실부터 건물 대행관리까지 ② 건물주는 한 곳에 요청, 브링케어가 완료까지 관리 ③ "혼자 관리하면 15만 원, 함께 관리하면 8.9만 원".
- 실적 페이지: 7동/7곳/10건+/12건 + "말로 만든 서비스가 아니라, 실제 현장에서 만들고 있는 관리체계입니다".
- 요금: 지역 공동관리 89,000원/동, 공용부 청소 6~8만, 전문작업 실작업비 5%. 실제 수리·청소비는 별도 표기(포함처럼 보이지 않게).

## 4. 이미 만들어 둔 제안서 자산
- **PPT 템플릿**: `docs/templates/브링_템플릿_건물주제안서.pptx`(6PP 골격 + 가이드 문구 포함, 제작 완료). 표지 "혼자 관리하면 15만 원, 함께 관리하면 8.9만 원".
- **제안서 작성 마스터 매뉴얼(Word)**: 책 3권 종합(제안서의 정석 6PP + 레이아웃 아틀라스 120 + AI로 완성하는 제안서). ※ 저작권상 사용자에게 파일로 전달, 레포 커밋 안 함.
- **대표자 필수 장착 리스트**(B방)에 6PP→브링 매핑 수록.

## 5. 근거로 쓸 확정 데이터 (지어내지 말 것)
- 회사: 브링엔지니어링(개인사업자, 대표 서창환). 원주 거점, 핵심 권역 우산동(확장 단계·단구·관설).
- BM: 원주 소형 임대건물(원룸·다가구) 권역 공동관리 'Zone'. 서비스 사이클: 관리→퇴실→청소·수리→공실준비→임대→입주→정기관리.
- 가격(2026-08): 공동관리 89,000원/동, 개별 150,000원, 공용부청소 3/4/5층 6/7/8만, 입주청소 10만~, 전문작업 5% 마크업.
- 실적: 관리 7동·정기청소 7곳·입주청소 10건+·수리 12건.
- 데이터(ValueScope): 원주 다가구 5,129동·26,825세대, 밀집블록 218개, 공인중개사 786곳.
- 중개보수: 건물주·임차인 모두 법정 기준(“건물주 중개보수 없음” 표현 폐기).
- 영업 트리거: **공실 해결**을 전면.

## 6. 제안서 유형별 방향
- **건물주 제안**: 위 6PP + 10p 구조. 특정 권역(예: 우산동) 데이터로 개인화.
- **투자 제안**: B방 IR덱·사업계획서 초안·재무모델과 숫자 정합. TAM 등 최고위험 수치는 반드시 검증.
- **정부/지원사업**: 소셜벤처 과제4(AI 기반 소형 임대건물 공동운영 플랫폼) 톤. 업종코드 자격 사전확인(MASTER §8·§11).
- **조달**: "분산형 소규모 공공시설 지역 공동관리 서비스"(BRING 이름·AI 앞세우지 않음).

## 7. 작성 원칙 (환각 방지)
- 수치·기관명·법령은 사람이 확인. 미검증치는 `[확인 필요]`/`[원본 대조 필수]`로 태깅.
- TAM·CAGR·해외 통계 = 최고위험. 본문에 확정처럼 쓰지 말 것.
- 저작권: 책 원문 복붙 금지, 재서술. 책 기반 매뉴얼은 사용자 파일로만 전달.
