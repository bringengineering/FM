# R&D 모듈 비활성화·복귀

이 설정은 해당 PC의 CRM 프로세스에 적용합니다. 서버 전체 권한 취소나 이미 열린 다른 PC의 중단을 대신하지 않습니다.

1. 미저장 초안을 내보내고 CRM을 정상 종료합니다.
2. PowerShell에서 `$env:BRING_RND_ENABLED='0'`을 설정한 뒤 해당 CRM 실행 파일을 실행합니다. 영구 적용은 운영 담당자가 사용자 환경 변수로 지정합니다.
3. R&D 메뉴가 숨겨지고 Main R&D 읽기·쓰기·승인 관리·업로드·내보내기 요청이 거부되는지 확인합니다. 기존 CRM 계정·고객 기능은 계속 사용할 수 있습니다.
4. 다시 활성화할 때 CRM 종료 후 `Remove-Item Env:BRING_RND_ENABLED` 또는 값을 `1`로 설정하고 재시작합니다. 사용자 환경 변수로 지정했다면 같은 범위에서 제거해야 합니다.

이 절차는 Firebase·Drive 자료를 삭제하거나 수정하지 않습니다. 재시작이므로 세션 초안은 사전에 보관해야 합니다. 진행 중인 작업은 정상 완료 여부를 먼저 확인하세요. 신규 데이터 마이그레이션·과거 버전 설치에 의한 복귀는 별도 절차입니다.

검증: 소스와 Windows 검토 빌드에서 비활성 메뉴·Main IPC 거절·CRM 로그인 및 고객 이동 확인. 기본 활성 빌드의 전체 R&D 화면 시험도 통과. 실제 운영 데이터 복귀 및 두 PC 중단 검수는 남아 있습니다.
