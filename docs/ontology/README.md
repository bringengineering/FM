# BRING 서비스 운영 온톨로지

`bring-service-operations-v1.json`은 CRM·클리닝센터·현장 작업·매출 장부가 같은 개념과 식별자를 쓰도록 하는 최소 계약입니다. 별도 그래프 DB나 복제 고객 DB가 아니며, 기존 CRM과 장부가 계속 원본입니다.

`workflowTermMappings`는 승인된 설계 문서에서 사용하는 한국어 상태 표현을 API의 영문 정식 상태 ID에 연결합니다. 이는 과거 저장 데이터에서 별칭을 발견했다는 뜻이 아니며, 기존 레코드의 상태를 자동 변환하지 않습니다. 저장된 옛 상태값은 실제 데이터와 의미를 확인한 뒤 별도 이행 계획을 승인받아야 합니다.

주문은 기존 고객·건물의 정식 ID를 참조합니다. 견적·현장 실행·사진·청구·입금은 각 기존 모듈을 유지하고, 연결이 실제 구현될 때 `cleaningOrderId` 등 명시적 참조를 추가합니다. 온톨로지의 관계가 아직 전부 화면이나 데이터베이스에 구현됐다는 뜻은 아닙니다.

Firebase Functions는 인증·권한·검증·원자적 저장을 담당합니다. n8n은 현재 운영 중이라고 확인되지 않았고, 추후 사용하더라도 알림과 재시도 가능한 주변 자동화만 맡깁니다. 핵심 고객·주문·작업·청구 데이터를 직접 쓰는 원본 시스템으로 사용하지 않습니다.

TV는 서버가 만든 개인정보 없는 집계만 읽습니다. 상세 주문·고객·출입·증거 링크는 TV projection에 포함하지 않습니다.
