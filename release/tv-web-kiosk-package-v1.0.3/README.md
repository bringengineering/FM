# BRING TV 통합 설치 프로그램 v1.0.3

## 설치

1. ZIP 파일의 압축을 모두 풉니다.
2. `BRING-TV-설치.cmd`를 더블클릭합니다.
3. 설치 직후 열리는 TV 운영보드에서 등록 코드를 확인합니다.
4. 다음 Windows 로그인부터 TV 운영보드가 자동으로 실행됩니다.

TV 운영보드 주소:

`https://bring-crm-ai-gateway.bringengineering1008.workers.dev/tv`

설치 프로그램은 Microsoft Edge를 우선 사용하며, Edge를 찾지 못하면 Google Chrome을 사용합니다.

## 오류가 발생하면

바탕화면의 `BRING-TV-설치-오류.txt`와 이 패키지의 `BRING-TV-설치복구-프롬프트.txt`를 함께 담당자 또는 AI에게 전달하세요.

비밀번호, 인증코드, 쿠키, API 키는 입력하거나 공유하지 마세요.

## 제거

`BRING-TV-삭제.cmd`를 실행하면 BRING TV 자동 실행 바로가기만 제거됩니다. 다른 사용자 자료와 TV 등록 정보는 삭제하지 않습니다.

## 패키지 원칙

- 기존 v1.0.2 릴리스를 덮어쓰지 않습니다.
- 비밀번호, 인증코드, 쿠키, API 키를 포함하지 않습니다.
- 설치 실패 기록은 바탕화면에만 생성됩니다.
