BRING TV 운영보드 CMD 전용 설치판 v1.0.4

[설치]
1. 받은 ZIP 파일을 새 폴더에 모두 압축 해제합니다.
2. 압축 해제한 폴더의 BRING-TV-설치.cmd를 더블클릭합니다.
3. 설치 완료 문구가 나오면 아무 키나 누릅니다.
4. TV 운영보드가 Edge 또는 Chrome의 전체화면으로 열립니다.

[다음 부팅부터]
- 현재 Windows 사용자가 로그인하면 시작프로그램에 등록된 BRING-TV-자동실행.cmd가 운영보드를 자동으로 엽니다.
- 기존 전용 브라우저 프로필을 계속 사용하므로 TV 등록정보가 유지됩니다.
- 운영보드의 화면 전환과 데이터 새로고침은 서버에서 자동으로 처리합니다.

[지원 브라우저]
- Microsoft Edge 권장
- Google Chrome 지원

[자동실행 해제]
- BRING-TV-삭제.cmd를 더블클릭합니다.
- 시작프로그램 파일만 삭제하며 TV 등록정보와 브라우저 프로필은 남겨 둡니다.

[문제가 생긴 경우]
- 바탕화면의 BRING-TV-CMD-설치-오류.txt 내용을 확인합니다.
- 함께 제공된 BRING-TV-설치복구-프롬프트.txt 아래에 오류 내용을 붙여 진단을 요청합니다.
- 비밀번호, 인증코드, 쿠키, API 키는 누구에게도 보내지 않습니다.
