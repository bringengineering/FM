# BRING 무료 웹 TV 설치

## 준비

- Windows TV 컴퓨터
- Microsoft Edge
- 인터넷 연결
- BRING CRM 관리자 로그인

별도 EXE, 코드서명 인증서, 유료 TV 프로그램은 필요하지 않습니다.

## 설치

1. TV 컴퓨터에서 `install-bring-tv-web-kiosk.ps1`을 실행합니다.
2. Windows에서 로그아웃 후 다시 로그인하거나 시작프로그램의 `BRING TV 운영보드`를 실행합니다.
3. 전체화면에 표시된 8자리 코드를 확인합니다.
4. BRING CRM의 `회사 운영보드 → TV 기기 승인·관리`에서 코드와 기기 이름을 입력합니다.
5. `현재 운영보드 TV에 게시`를 눌러 첫 자료를 게시합니다.

이후에는 TV 컴퓨터가 켜지고 Windows에 로그인되면 Edge 전체화면이 자동 실행됩니다. 전용 Edge 저장공간에 승인 상태가 보관되므로 정상적으로 연결을 해제하지 않는 한 인증 코드를 다시 입력할 필요가 없습니다. 서버 화면은 웹에서 자동 반영되므로 TV 프로그램 업데이트는 없습니다.

기존 설치본에서 인증 코드가 반복해서 표시된다면 최신 `install-bring-tv-web-kiosk.ps1`을 TV 컴퓨터에서 한 번만 다시 실행합니다. 기존 시작프로그램 바로가기가 안전하게 교체됩니다. 새로 표시되는 코드 한 번을 CRM에서 승인한 뒤에는 재부팅·자동 새로고침 후에도 연결 상태가 유지됩니다.

## 확인

- 회사 현황, 팀 성과, 업무지시, 이슈·공지, 일정 화면이 순환하는지 확인합니다.
- CRM에서 공지를 바꾸고 다시 게시했을 때 TV가 15초 안에 바뀌는지 확인합니다.
- 네트워크를 잠시 끊었을 때 최근 게시자료를 유지하고, 다시 연결했을 때 정상 복구되는지 확인합니다.
- CRM에서 기기 연결을 해제했을 때 TV가 새 승인 코드 화면으로 돌아가는지 확인합니다.

## 제거

`uninstall-bring-tv-web-kiosk.ps1`을 실행합니다. BRING TV 시작프로그램 바로가기만 제거하며 Edge의 다른 설정과 자료는 삭제하지 않습니다.
