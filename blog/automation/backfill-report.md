# 브링케어 블로그 성과 원장 초기 이관 보고서

- 확인한 공개 글 수: 1
- 원장에 이관한 글 수: 3
- 공개 URL을 확인한 글 수: 1
- 로컬 원고만 확인되어 URL을 `NA`로 둔 글 수: 2
- 성과 데이터가 있는 글 수: 0
- 성과 데이터가 없어 `NA`로 둔 글 수: 3
- 중복 또는 분류 충돌: 없음
- 첫 자동 기준선 활성화까지 필요한 추가 글 수: 같은 비교군 기준 최소 17개

## 이관 원칙

공개 URL은 대화와 로컬 자료에서 직접 확인된 값만 기록했다. 네이버 공개 목록을 안정적으로 전수 조회할 수 없는 상태에서는 URL·발행 시각·조회수·유입·상담을 추정하지 않는다. 로컬 원고가 존재하지만 공개 여부를 확인하지 못한 글은 `public_url=NA`로 보존하고, 이후 로그인된 공개 목록 검수 때 보강한다.

## 다음 보강 작업

1. 로그인된 네이버 블로그 글 목록에서 공개 URL과 정확한 발행 시각을 대조한다.
2. 크리에이터 어드바이저에서 확인 가능한 기간의 글별 성과를 실제 수치로 입력한다.
3. 동일 역할·주제 축의 비교 글이 20개가 되기 전까지 중앙값 기준을 `잠정`으로 표시한다.
