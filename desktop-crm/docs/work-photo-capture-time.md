# 작업 결과보고서 원본 촬영시각

- 승인된 사진 검토 화면을 유지하고 사진별 촬영 날짜·시간과 정보 보유 장수를 표시한다.
- Drive에서 선택하고 인증된 세션에 등록된 JPEG 원본의 EXIF `DateTimeOriginal`과 `OffsetTimeOriginal`만 읽는다. `createdTime`, 파일 수정일, `DateTimeDigitized`는 촬영 근거로 사용하지 않는다.
- JPEG가 아니거나 EXIF가 없거나 손상된 파일은 촬영시간 없음으로 표시한다. HEIC 등 미지원 원본의 시간을 추측하지 않는다. 기존 사진 변환·시각 분류·수동 지정은 유지한다.
- 공간·대상 분류 후 동일 구역끼리 비교한다. 30장 초과 비교 그룹은 이른 사진과 늦은 사진이 같은 요청에 포함되도록 교차 배치한다.
- 날짜·시간대가 같은 원본 사진에 한해 비교 요청의 첫 사진으로부터 상대 분(0–1439)을 전달한다. 원본 날짜, GPS, 기기정보, 이름, Drive 링크는 Gemini에 보내지 않는다. 이미지 자체에 보이는 개인정보는 기존 안내대로 포함될 수 있다.
- 확실한 시각 변화는 기존 추천 근거로 유지한다. 동일 장면 점수 95 이상, 전후 점수 85 이상, 원본 시간 간격 40분 이상일 때 시간 보조 추천도 허용한다. 모델 점수는 보정된 확률이 아니며 추천에는 사용자 확인이 필요하다.
- 전체 사진을 단일 시간 경계로 나누지 않는다. 중간에 찍은 작업 전 사진도 해당 장면의 늦은 사진과 비교한다. 역순인 추천, 수동 지정과 충돌하는 추천, 날짜·시간대가 다른 시간 추천은 적용하지 않는다.
- 촬영시간이 없는 사진도 기존 시각 비교와 수동 지정으로 처리할 수 있다. 확인한 사진만 초안에 적용하며 완료 상태는 자동 변경하지 않는다.
- 원본은 수정하거나 저장하지 않는다. 원본을 읽은 후 메타데이터 없는 작은 JPEG만 현재 Drive 선택 세션에 캐시하여 비교 시 재다운로드를 피한다.

검증: JPEG 양쪽 바이트 순서, 깨진 오프셋·잘린 파일·날짜 유효성, 업로드일 제외, 상대 시각만 외부 전송, 미등록 ID·클라이언트 시각 주입 거부, 중간 전 사진, 역순/수동 충돌, 58장 비교 경계, 실제 렌더러의 시간 표시·확인 절차·실패 시 사진 유지.
