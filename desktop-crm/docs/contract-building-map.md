# 계약 건물 지도

CRM → 계약 고객 관리 아래의 **계약 건물 지도**. 키가 없는 설치본에서도 건물 목록·계약 상태·고객 상세 이동은 작동한다. 기본값은 미설정/사용 안 함이며 이 상태에서는 지도 또는 주소 검색 API를 호출하지 않는다. 가상 좌표나 다른 고객의 주소를 사용하지 않는다.

## 회사 공용 키 (모든 PC)

키를 `crm-ai-worker` Cloudflare Secret `VWORLD_API_KEY`로 한 번만 등록하면 모든 CRM 설치본이 지도를 사용한다. PC에 별도 키가 없으면 CRM은 로그인한 직원 토큰으로 회사 지도 서버(`/v1/map`, `action: "key"`)에서 키를 받아 메모리에만 두고(디스크·공용 DB에 저장하지 않음), **브이월드는 PC가 직접 호출**한다.

서버가 브이월드를 대신 호출하지 않는 이유: 2026-11-03 실제 CRM으로 확인한 결과, 같은 키가 PC(한국 IP)에서는 동작했지만 Cloudflare Worker에서 호출하면 주소 조회·타일이 모두 실패했다(`MAP_UNAVAILABLE`, 약 3초). 브이월드가 Cloudflare 출구 IP를 받지 않는 것으로 보인다. Worker의 `geocode`/`tile` 동작은 진단용으로 남겨 두었고, 실패 시 `reason`(예: `http_403`, `vworld_INVALID_KEY`, `fetch_error`)만 돌려준다.

1. `crm-ai-worker`에서 `npx wrangler secret put VWORLD_API_KEY` 실행 후 키 입력(채팅·소스·`.env`에 쓰지 않는다).
2. `npx wrangler deploy`로 Worker 배포. `GET /health`의 `contractMap`이 `true`이면 준비 완료.
3. 이 경로가 포함된 CRM 버전을 배포.

`key` 요청은 Firebase ID 토큰과 `crmCompany/access/{uid}` 기록(활성 admin/member/viewer, 마케팅 전용·비밀번호 변경·설정/삭제 대기 제외)을 확인한 뒤에만 키를 돌려주며 사용자별 분당 600회(`MAP_RATE_LIMITER`)로 제한한다. 브이월드 키는 웹 지도 타일 URL에 노출되도록 설계된 키이므로, 권한 있는 직원 PC의 개발자 도구에서는 볼 수 있다. 키가 유출되면 브이월드에서 재발급 후 Secret만 교체한다(CRM 재배포 불필요, PC는 30분 안에 새 키를 받는다). 서버 사용을 끄려면 `VWORLD_MAP_ENABLED`를 `"false"`로 바꿔 배포하거나 Secret을 삭제한다.

## PC별 키 (선택)

PC에 키를 저장하고 사용을 켜면 그 PC는 서버 대신 자기 키로 브이월드를 직접 호출한다.


1. CRM 관리자로 로그인하고 지도 탭 하단의 `지도 연결 설정 · 이 PC에만 적용`을 펼친다.
2. 회사 명의로 발급한 브이월드 키를 비밀번호 입력란에 입력한다. 채팅·보고서·소스·공용 DB에는 붙여 넣지 않는다.
3. 브이월드의 2D 지도/배경지도/지오코더 사용 권한과 키 만료일을 확인한다. 배경 타일은 공식 WMTS Base 형식을 사용하므로 인증키 설정에서 WMTS/TMS 권한이 별도로 요구되면 해당 권한도 신청한다.
4. **운영키·회사 업무용 이용 허락 및 사용 조건을 실제로 확인한 후에만** 사용 확인과 지도 연결 사용을 선택하고 저장한다. 개발키 발급만으로 운영 또는 상업적 이용 허락이 완료된 것으로 간주하지 않는다.
5. 공개 건물 주소로 조회 결과와 실제 위치를 확인한다. 2026-11-02에 APP 유형 개발키로 Referer 없는 지오코딩·WMTS Base 타일 호출이 성공하는 것을 확인했다.

설정은 Windows 사용자 프로필의 Electron safeStorage로 암호화되어 저장된다. 평문 저장으로 대체하지 않으며 키 값은 조회 API로 반환하지 않는다. 공용 Firebase 규칙·데이터는 변경하지 않는다. **이 설정은 PC별**이며 회사 전체의 다른 설치본에 자동으로 전달되지 않는다. 키가 비어 있는 저장은 기존 키를 유지한다. 사용을 끄려면 지도 연결 사용을 해제해 저장한다.

## 화면 사용법

- 지도는 끌면 손을 따라 움직이고, 마우스 휠·더블클릭(Shift+더블클릭은 축소)·＋/－ 버튼·키보드 ＋/－로 확대·축소한다. 방향키로도 이동한다.
- 목록에서 건물을 고르면 지도가 그 건물로 이동하고, 지도에서 표식을 고르면 지도는 그대로 두고 목록이 그 건물로 스크롤된다. 목록에 마우스를 올리면 해당 표식이 강조된다.
- 고른 건물은 지도 왼쪽 아래 카드에 이름·상태·주소·고객·다음 작업과 `상세 보기`·`이 건물로 이동`·`주소 복사` 버튼으로 표시한다. 계약 목록은 지도 아래 상세에 있다.
- 건물 이름은 확대(15단계 이상)하면 모두, 멀리서는 고른 건물·마우스를 올린 건물만 표시한다.
- 상태 필터나 검색을 바꾸면, 직접 지도를 움직이지 않은 경우 보이는 건물에 맞춰 화면을 다시 맞춘다. `전체`는 보이는 건물 전체로 맞춘다.
- `주소 복사`는 이 PC 클립보드에만 복사하며 외부로 보내지 않는다.

## 데이터와 안전장치

- 기존 CRM 계약의 정확한 customerId/buildingId로만 연결한다. 취소·삭제·보관 계약, 없는 고객·건물은 제외한다. 상태를 알 수 없는 계약은 확인 필요로 표시하며 지도 표식을 만들지 않는다.
- 계약 중(진행 중·종료 예정)은 파란 ★, 계약 준비는 주황 ○, 종료는 회색 ● 표식(지도 왼쪽 위 범례). 건물마다 하나의 표식이며 계약 중 → 예정 → 종료 순으로 대표 상태를 정한다. 기간만 보고 계약을 자동 종료하지 않는다.
- 주소가 없거나 검색이 안 되면 목록에 확인 필요로 남기고 좌표를 추측하지 않는다. 정확한 지번 주소가 있으면 도로명 조회 실패 시 지번으로 재조회한다.
- 외부에는 해당 계약 건물 주소만 보낸다. 고객명·연락처·계약 정보는 보내지 않는다. 좌표와 타일은 화면의 메모리에서만 쓰며 DB·파일·브라우저 저장소에 저장하지 않는다. 화면 전환·로그아웃·권한 변경 시 폐기하고 늦게 도착한 응답은 무시한다.
- 고정 HTTPS 목적지 `api.vworld.kr`만 요청하며 리디렉션을 금지한다. 시간·동시 처리·본문 크기·좌표/타일 범위·요청 횟수를 제한한다. 반환 이미지의 MIME/PNG 서명/256×256 크기를 검증한다. 외부 스크립트·HTML을 실행하지 않는다.
- 실패 메시지는 키·주소·외부 응답 본문을 포함하지 않는다. 유료 공급자나 다른 공개 지오코더로 자동 우회하지 않는다.

- 2D 지도: https://www.data.go.kr/data/3052419/openapi.do (무료, 출처표시)
- 브이월드 공식 교육 예제: https://github.com/V-world/V-world_API_sample/tree/master/브이월드_교육/2026년_브이월드_교육 (WMTS Base 및 getcoord 형식 참조; 공개 예제의 키는 사용하지 않는다)

문서의 비용 안내는 지도 API에 관한 것이다. 회사의 기존 서버·인터넷·CRM 인프라 비용이 없어진다는 의미가 아니다. 무료 서비스도 제공 한도·이용 정책·만료일이 적용된다.
