# BRING CRM Desktop

이 디렉터리는 BRING CRM 데스크톱 소스와 이후 변경사항을 관리한다. `v1.7.0`부터 기존 로그인과 공유 저장소 안에서 건물 중심 영업 관리, 13단계 퍼널, 영업 표준, 완료 증거 기반 지표를 함께 제공한다.

## 검증과 Windows 패키지

```powershell
npm.cmd install
npm.cmd test
npm.cmd run smoke
npm.cmd run build:win
```

Firebase, CRM 데이터와 사용자 캐시는 빌드 산출물에 포함하지 않는다. `kr.co.bringengineering.crm` 앱 ID와 `bring-crm-desktop` 패키지 이름은 기존 설치본의 업데이트 호환성을 위해 변경하지 않는다.

## 메신저 첨부와 알림

- 메시지 입력 영역에 파일을 끌어 놓거나 첨부 버튼으로 문서와 이미지를 전송할 수 있습니다.
- 일반 HWP 문서는 전송할 수 있으며, 암호·배포용 문서와 허용 크기를 넘긴 파일은 안전을 위해 차단합니다.
- 새 메시지가 오면 Windows 알림을 표시하고, 알림을 선택하면 해당 대화를 엽니다. 시스템 알림을 사용할 수 없으면 작업 표시줄에서 알립니다.

## AI 비서와 상담 자동정리

CRM의 `AI 비서`는 상담·다음 행동·영업 문자·작업보고 초안을 만들고, 상담 기록의 `AI로 정리`는 입력한 원문을 검토 가능한 필드로 나눕니다.

- AI 결과는 초안이며 자동 저장되거나 고객에게 자동 발송되지 않습니다.
- 상담 원문은 직원이 `제안 적용`을 누르기 전까지 변경되지 않습니다.
- 개인 메모는 AI 요청 문맥에서 제외합니다.
- 전화번호·이메일·계좌번호·주민번호 형태와 상세주소는 회사 AI Gateway에서 마스킹합니다.
- Groq API 키는 Cloudflare Secret에만 있으며 CRM 코드, GitHub, 설치 파일에 포함하지 않습니다.
- 무료 한도나 AI 장애가 발생해도 고객·상담·작업 저장 기능은 계속 사용할 수 있습니다.
- 무료 한도 초과 시 자동 유료 결제로 전환하지 않고 AI 요청을 중지합니다.
